# Al-Khwarizmi's Algorithms — Step-Through Visualizer

Step through sorting algorithms visually. The word "algorithm" comes from Al-Khwarizmi's Latinized name "Algoritmi."

## Concept

Muhammad ibn Musa al-Khwarizmi pioneered systematic step-by-step problem solving. This app lets students visualize how algorithms work by stepping through bubble sort, selection sort, and insertion sort one comparison at a time.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Three sorting algorithms: Bubble, Selection, Insertion
- Step-by-step or auto-run animation
- Color-coded comparisons and swaps
- Pseudocode display with highlighting
- High score persistence via localStorage

## Lesson

Al-Khwarizmi gave the world the concept of algorithmic thinking — breaking complex problems into clear, repeatable steps. Every computer program runs on algorithms named after him.
