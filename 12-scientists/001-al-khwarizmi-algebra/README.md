# Al-Khwarizmi's Algebra — Visual Equation Balancing

Solve original algebra problems from Al-Khwarizmi's 9th-century masterwork using visual equation balancing with al-jabr and al-muqabala operations.

## Concept

Muhammad ibn Musa al-Khwarizmi (780-850 CE) wrote "Al-Kitab al-Mukhtasar fi Hisab al-Jabr wal-Muqabala," the book that gave algebra its name. Students solve equations from his six standard forms using the same methods he taught: al-jabr (completion) and al-muqabala (balancing).

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Visual balance board showing both sides of the equation
- Step-by-step solution walkthrough for each problem
- 10 problems covering Al-Khwarizmi's six equation types
- High score persistence via localStorage

## Lesson

Al-Khwarizmi systematized the solving of equations, creating the foundation for modern algebra. His methods of al-jabr and al-muqabala are still the core operations we use today.
