# Ibn al-Haytham Optics Lab

Experiment with light rays, lenses, and mirrors. Build a camera obscura and discover how Ibn al-Haytham founded modern optics.

## Concept

Interactive educational app about Muslim scientific contributions. Ibn al-Haytham Optics Lab (Laboratoire Optique Ibn al-Haytham / مختبر البصريات لابن الهيثم).

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Interactive hands-on educational experience
- High score persistence via localStorage
