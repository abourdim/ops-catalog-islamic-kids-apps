# Armor & Weapons Workshop

Interactive encyclopedia and quiz about Islamic-era weapons and armor. Learn about swords, shields, bows, helmets, and more used by the Prophet and his companions, then identify them from descriptions.

## Concept

Players read detailed descriptions of historical weapons and armor, then identify them from four options. Each item includes historical context about who used it and in which battles.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- 4-option quiz with randomized distractors
- Items shuffled each playthrough

## Lesson

Knowledge of tools and equipment was essential for the Muslim community. The Prophet valued craftsmanship and preparation, teaching that readiness is part of faith and that every tool has its proper use and purpose.
