# Purify the Kaaba — Mecca Idol Remover

**Remove the idols, restore Tawheed**

A canvas-based tap-to-remove game for Muslim kids about the historic purification of the Kaaba during Fath Makkah (Conquest of Makkah, 8 AH / 630 CE).

## Gameplay

- **360 idol markers** are arranged in concentric circles around the Kaaba (black cube at center)
- **Tap mode**: click/tap idols one by one to remove them
- **Sweep mode**: drag across multiple idols to remove them quickly (press `S` to toggle)
- Each removed idol crumbles with a particle animation
- Counter tracks remaining idols: "360/360" counting down
- As idols are removed, the Kaaba glows brighter with golden light

## Special Idols

| Idol | Taps Required | Description |
|------|--------------|-------------|
| **Hubal** | 3 | Chief idol of Quraysh, largest and most prominent |
| **al-Lat** | 2 | Stone idol worshipped in Taif (Quran 53:19) |
| **al-Uzza** | 2 | Idol near Makkah (Quran 53:19) |
| **Manat** | 2 | Idol of fate between Makkah and Madinah (Quran 53:20) |

## Victory Sequence

1. Kaaba shines with golden rays of light
2. Bilal ibn Rabah (RA) appears atop the Kaaba calling the Adhan
3. First congregational prayer shown at the purified Kaaba
4. Lesson displayed: Tawheed restored, Ibrahim's legacy renewed

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based rendering with particle animations
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Web Audio API sound effects (no audio files needed)
- High score tracking (best time) via localStorage
- Keyboard shortcuts: `Enter` (start), `S` (toggle mode), `H` (help), `M` (mute)
- Responsive canvas that adapts to screen size
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Persistent preferences (theme, language, sound, high score)
