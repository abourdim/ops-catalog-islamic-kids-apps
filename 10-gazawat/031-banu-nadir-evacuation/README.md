# Banu Nadir — The Cost of Betrayal

Canvas-based strategic siege game for Muslim kids. Part of the Workshop-Diy Islamic Kids Apps catalog.

## Overview

An interactive 7-phase game teaching the historical siege of Banu Nadir (4 AH / 625 CE). Players learn about the consequences of treachery, difficult military decisions justified by Quranic revelation, and the Prophet's care for the Muhajirun refugees.

## Phases

1. **The Assassination Plot** — Banu Nadir plot to drop a boulder on the Prophet ﷺ; Allah warns him through revelation
2. **The Fortress Map** — Study the canvas map showing Banu Nadir fortresses surrounded by date palm gardens
3. **Position Siege Forces** — Drag and drop archer, infantry, and cavalry units around the fortresses
4. **The 15-Day Siege** — Watch the siege progress; face the palm tree dilemma on Day 5
5. **Quranic Revelation** — Surah Al-Hashr 59:5 justifies the decision regarding the palm trees
6. **The Exodus** — Banu Nadir surrender and depart with what their camels can carry
7. **Land Distribution** — Properties distributed to the Muhajirun who had nothing

## Lessons

- Treachery has consequences — breaking treaties leads to loss
- Difficult military decisions can be justified by divine guidance
- The Prophet ﷺ cared deeply for refugees (Muhajirun)
- Even enemies were treated with mercy — allowed to leave with possessions

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based map with drag-and-drop unit placement
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual: English, French, Arabic (RTL support)
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Keyboard shortcuts (Enter to advance, 1-2 for choices, Esc to close help)
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Touch support for mobile devices
- Responsive design

Open `index.html` in any modern browser. No server required.
