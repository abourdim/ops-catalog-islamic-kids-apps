# Conquest of Mecca — The Peaceful Victory

> **Workshop-Diy** — Canvas-based strategic planner game for Muslim kids

## Overview

An interactive HTML5 Canvas game that teaches children about Fath Makkah (the Conquest of Mecca, 8 AH / 630 CE) — one of the most remarkable events in Islamic history, where 10,000 Muslims entered Mecca almost entirely without bloodshed.

## Gameplay Phases

| Phase | Description |
|-------|-------------|
| 1. **Assign Commanders** | Drag 4 commander portraits to the 4 entry points (north, south, east, west) |
| 2. **Divide Troops** | Use sliders to distribute 10,000 soldiers across the 4 divisions |
| 3. **Give the Order** | Choose the correct standing order: "Do not fight unless attacked" |
| 4. **March** | Watch the animated simultaneous entry from all 4 directions toward the Kaaba |
| 5. **Remove Idols** | Tap/click 360 idols around the Kaaba to remove them |
| 6. **Prophet's Entry** | The Prophet ﷺ enters humbly on his camel, head bowed |
| 7. **General Amnesty** | Former enemies forgiven — lesson on mercy and forgiveness |

## Commanders

- **Khalid ibn al-Walid** — South Pass (encounters brief resistance)
- **Zubayr ibn al-Awwam** — North Pass
- **Abu Ubaidah ibn al-Jarrah** — West Pass
- **Sa'd ibn Ubadah** — East Pass

## Key Lesson

> *Mercy in victory. No revenge. Forgiveness.*

The Prophet ﷺ declared: "Go, you are free!" — pardoning even those who had persecuted Muslims for years.

## Features

- Single HTML file, zero dependencies, fully offline
- HTML5 Canvas map with animated march sequences
- Drag-and-drop commander assignment
- Interactive troop allocation sliders
- Tap-to-remove idol mechanic (360 idols)
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- 3 languages: English, French, Arabic (RTL)
- Sound effects via Web Audio API (no files)
- High score persistence via localStorage
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Keyboard shortcuts
- Responsive design — works on phone, tablet, desktop

## Storage

| Key | Purpose |
|-----|---------|
| `wdiy-hs-mecca-conquest` | High score |
| `wdiy-lang` | Language preference |
| `wdiy-theme` | Theme preference |
| `wdiy-mute` | Sound mute state |

## Usage

Open `index.html` in any modern browser. No server required.
