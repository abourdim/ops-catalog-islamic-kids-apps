# Battle of the Masts — Dhat al-Sawari (655 CE)

Canvas-based naval strategy game for Muslim kids about the first major Muslim naval battle.

## Game Overview

- **Event**: Battle of Dhat al-Sawari (Battle of the Masts), 655 CE
- **Location**: Mediterranean Sea near Lycia (southern Turkey coast)
- **Muslim Commander**: Abdullah ibn Sa'd ibn Abi Sarh
- **Enemy Commander**: Emperor Constans II of Byzantium
- **Forces**: 200 Muslim ships vs 500 Byzantine ships

## Gameplay Phases

1. **Position Fleet** — Drag Muslim ships (green) into battle formation on the canvas
2. **Choose Strategy** — "Ram them" vs "Board them" (boarding is correct — converts naval battle to close combat)
3. **Battle Animation** — Ships grapple, Muslim soldiers overwhelm Byzantine sailors in hand-to-hand combat
4. **Victory** — Byzantine fleet destroyed, Emperor Constans barely escapes
5. **Lesson** — First time Muslims controlled the Mediterranean; adapt and innovate

## Historical Context

Muawiyah ibn Abi Sufyan convinced Caliph Umar and then Caliph Uthman to build a Muslim navy. Arabian desert people became a naval power. The Muslim strategy of tying ships together and boarding turned their land-combat advantage into a decisive naval victory.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based rendering with ship animations
- Drag-and-drop ship positioning
- 8 CSS themes (Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand)
- Trilingual (EN / FR / AR with RTL support)
- Web Audio API sound effects
- Keyboard shortcuts (1-4 for answers, Enter to start, Escape to close help)
- LocalStorage persistence (theme, language, sound, high score)
- Sidebar help panel (FAQ, How-To, Wiki)
- Responsive canvas sizing

## Storage Keys

- `wdiy-hs-naval-battle` — High score
- `wdiy-theme` — Theme preference
- `wdiy-lang` — Language preference
- `wdiy-mute` — Sound toggle
