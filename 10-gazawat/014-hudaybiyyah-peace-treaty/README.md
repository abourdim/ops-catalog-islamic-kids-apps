# Treaty of Hudaybiyyah — Interactive Negotiation Game

**The victory that looked like defeat**

An interactive canvas-based negotiation simulation for Muslim kids, teaching the wisdom behind the Treaty of Hudaybiyyah.

## Game Overview

Players experience the historic events at Hudaybiyyah through three phases:

### Phase 1 — The Journey
- 1,400 Muslims set out for Umrah in ihram
- Quraysh block them at Hudaybiyyah
- Uthman (may Allah be pleased with him) sent as envoy
- Rumor of Uthman's death spreads
- Bay'at al-Ridwan — the Pledge under the Tree

### Phase 2 — The Negotiation
Suhayl ibn Amr presents treaty terms one by one. Each seems unfair, but the player learns the Prophet's (peace be upon him) wisdom in accepting:

1. Bismillah removed from heading
2. "Messenger of Allah" removed — write "Muhammad ibn Abdullah"
3. Muslims return this year, come next year
4. Quraysh defectors to Muslims must be returned
5. Muslim defectors to Quraysh won't be returned
6. 10-year peace treaty — the real victory

### Phase 3 — The Victory
- Surah Al-Fath revealed (Quran 48:1)
- Statistics: 1,400 at Hudaybiyyah vs 10,000 at Conquest of Makkah
- More conversions in 2 years than in all previous 19 years
- Key lessons on trust, patience, and long-term thinking

## Key Lesson

Short-term sacrifice for long-term gain. Trusting the Prophet's (peace be upon him) wisdom even when the outcome seems unfair.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual: English, French, Arabic (RTL)
- Web Audio API sound effects (no external files)
- Keyboard shortcuts (Enter to continue, 1/2 for accept/reject)
- Persistent preferences (theme, language, sound, high score)
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Responsive design for mobile, tablet, and desktop

## Storage

- `wdiy-hs-hudaybiyyah` — best completion time
- `wdiy-lang` — language preference
- `wdiy-theme` — theme preference
- `wdiy-mute` — sound preference

## Usage

Open `index.html` in any modern browser. No server required.
