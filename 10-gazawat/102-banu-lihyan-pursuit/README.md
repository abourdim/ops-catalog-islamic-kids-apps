# Banu Lihyan Pursuit — Tracking & Pursuit Game

Interactive tracking and pursuit game based on the Prophet's (peace be upon him) expedition against Banu Lihyan (6 AH / 627 CE).

## Concept

After the treacherous massacre at Bi'r Ma'una where Banu Lihyan killed 70 Quran reciters, the Prophet led an expedition to pursue them. The player follows trail markers, manages army speed vs stealth, and makes pursuit decisions across desert terrain.

## The 8 Phases

| # | Phase | Description | Key Lesson |
|---|-------|-------------|------------|
| 1 | Trail Discovery | Find the initial trail toward Banu Lihyan | Careful observation is key |
| 2 | Speed vs Stealth | Balance army movement speed with concealment | Strategic patience |
| 3 | Desert Navigation | Navigate harsh terrain using landmarks | Knowledge of land is power |
| 4 | False Trail | Identify and avoid a decoy trail | Critical thinking prevents traps |
| 5 | Water Rationing | Manage water supplies during pursuit | Resource management saves lives |
| 6 | Enemy Alert | React when the enemy learns of your approach | Adapt plans when detected |
| 7 | Show of Force | Demonstrate strength near enemy territory | Deterrence without bloodshed |
| 8 | Strategic Withdrawal | Decide when to return to Medina | Knowing when to withdraw is wisdom |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes with canvas-based trail visualization
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Interactive pursuit map with trail markers
- Web Audio API sound effects
- High score persistence via localStorage

## Lesson

Justice is pursued with patience and wisdom. Sometimes showing strength is enough — the expedition demonstrated Muslim resolve without unnecessary bloodshed.
