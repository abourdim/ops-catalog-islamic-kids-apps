# Farewell Pilgrimage Guard — Security Planning

Interactive security planning game about organizing protection for 100,000+ pilgrims during the Prophet's (peace be upon him) Farewell Pilgrimage (Hajjat al-Wada, 10 AH / 632 CE).

## Concept

The Farewell Pilgrimage was the only complete Hajj the Prophet performed, with over 100,000 Muslims. The player manages route planning, water supply, crowd control, and security across all Hajj sites — from Medina to Mecca, Arafat, Muzdalifah, and Mina.

## The 8 Phases

| # | Phase | Key Lesson |
|---|-------|------------|
| 1 | Route Planning | Staggered groups prevent congestion |
| 2 | Water Supply | Pre-positioned stations ensure safety |
| 3 | Camp at Dhul-Hulayfah | Organize teaching by sections |
| 4 | Mecca Crowd Control | Rotating groups for Tawaf safety |
| 5 | Day of Arafat | Human relay system for the sermon |
| 6 | Muzdalifah Night | Prioritize weak and elderly |
| 7 | Stoning at Mina | Flexibility reduces dangerous crowding |
| 8 | Lesson of the Hajj | Compassionate leadership organizes best |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes with canvas crowd visualization
- Safety and Order stat meters
- Trilingual with RTL support, Bismillah splash screen
- Web Audio API sounds, localStorage persistence

## Lesson

Compassionate, flexible leadership can organize the largest gatherings safely. The Prophet built systems that millions follow 1400 years later.
