# Banu Qaynuqa — When Treaties Are Broken

Interactive diplomacy and negotiation game for Muslim kids about the Banu Qaynuqa incident in early Islamic history.

## Overview

A 6-phase interactive story where players make diplomatic choices and learn about the Constitution of Medina, treaty obligations, consequences of betrayal, siege management, and merciful resolution.

## Phases

1. **The Treaty** — Read the Constitution of Medina terms; assess the treaty's fairness
2. **The Marketplace Incident** — A Muslim woman is harassed; choose how to seek justice
3. **Treaty Broken** — Banu Qaynuqa fortify and challenge Muslims; decide on response following Quranic guidance
4. **The 15-Day Siege** — Resource management (troops, supplies, patience) over 15 days of siege decisions
5. **Surrender & Intercession** — Banu Qaynuqa surrender; Abdullah ibn Ubayy pleads for leniency
6. **The Decision** — Exile with movable property; reflect on the lesson of mercy and justice

## Lessons

- Treaties are sacred obligations in Islam
- Justice requires proper process, not revenge
- Mercy even toward treaty-breakers
- Patience and discipline in hardship
- Right action transcends the motives of those around us

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Splash screen with bismillah
- Sidebar help panel (FAQ, How-To, Wiki)
- Keyboard shortcuts (1-4 for choices, Enter to start, Escape to close help)
- Web Audio API sound effects (no audio files)
- Wisdom score with localStorage high score persistence
- Theme, language, and sound preferences persisted in localStorage
- Timer tracking play duration

## Storage Keys

| Key | Purpose |
|-----|---------|
| `wdiy-hs-qaynuqa` | High score (wisdom %) |
| `wdiy-lang` | Language preference |
| `wdiy-theme` | Theme preference |
| `wdiy-mute` | Sound mute state |

## Usage

Open `index.html` in any modern browser. No build step or server required.
