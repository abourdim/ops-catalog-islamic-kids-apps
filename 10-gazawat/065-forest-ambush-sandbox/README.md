# Forest Ambush Sandbox — Concealment & Surprise

Interactive canvas strategy game where players plan ambush points in forested terrain, hiding units behind trees and setting chokepoints.

## Concept

Plan ambush points in a procedurally generated forest. Hide archers behind trees for concealment bonuses, position swordsmen at chokepoints, and set rope traps on the path. Inspired by Islamic military intelligence and reconnaissance tactics.

## Gameplay

- Procedurally generated forest with winding path each game
- Hide archers near trees for concealment (2x damage on first strike)
- Swordsmen engage in melee at chokepoints
- Rope traps slow enemies by 70% when triggered
- Units near trees get 30% damage bonus from cover
- Enemies march along the path; prevent them from escaping
- Max 5 enemies can escape before mission failure
- 5 waves of increasing enemy numbers and strength

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Procedural forest and path generation

## Lesson

Strategic intelligence, reconnaissance, and the element of surprise were key principles in Islamic military doctrine. The Prophet (peace be upon him) emphasized preparation and knowledge of terrain before any engagement.
