# Battle Terrain Analyzer

Interactive terrain analysis game using canvas-drawn maps from historical Islamic battles. Players identify strategic advantages like high ground, water sources, chokepoints, and natural barriers.

## Concept

The Prophet (peace be upon him) was a master strategist who used terrain to his advantage. Players analyze canvas-rendered terrain maps from Badr, Uhud, and the Trench, answering strategic questions about why specific terrain features mattered.

## The 3 Battles (6 Questions)

| Battle | Key Terrain Features |
|--------|---------------------|
| Badr (2 AH) | Wells, sun position, sand dunes |
| Uhud (3 AH) | Archer hill, Mount Uhud, mountain pass |
| Khandaq (5 AH) | Trench, mountains, city walls |

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-rendered terrain maps with color-coded features
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme-aware canvas rendering

## Lesson

Understanding terrain is essential to strategy. The Prophet chose battlefields carefully — securing water at Badr, using mountains at Uhud, and innovating with the trench at Khandaq. Good planning and use of the environment are forms of wisdom.
