# Battle Summary Encyclopedia — Interactive Reference

Interactive encyclopedia of all major Islamic battles from the Prophetic era through the Rashidun Caliphate.

## Concept

A comprehensive, searchable, filterable encyclopedia of 16 major Islamic battles. Each entry includes key facts (date, commander, forces, result), a historical lesson, and a quiz question. Browse by era, commander, or region.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes with expandable battle cards
- Search box for filtering by name, commander, or year
- Filter buttons: All, Prophetic Era, Rashidun Era, Arabia, Syria, Iraq, Persia, Egypt
- Quiz question in each battle entry with score tracking
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sound effects, localStorage persistence

## Lesson

Islamic history is rich with lessons of faith, strategy, mercy, and justice. Each battle teaches something unique about leadership and character.
