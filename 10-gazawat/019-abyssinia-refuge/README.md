# Refuge in Abyssinia

**When a Christian king protected Muslims**

An interactive canvas-based journey game for Muslim kids about the first Hijra to Abyssinia (Ethiopia).

## Game Phases

1. **Sea Journey** — Navigate a ship from Mecca across the Red Sea to Abyssinia by choosing the right wind direction.
2. **The Court of Najashi** — Witness Quraysh's envoy Amr ibn al-As arrive with gifts to convince the king to return the Muslims.
3. **Ja'far Speaks** — Interactive dialogue: choose which aspects of Islam Ja'far ibn Abi Talib presents to the court (monotheism, justice, honoring daughters, reciting Surah Maryam).
4. **The Just Verdict** — Najashi refuses to hand over the Muslims and grants them protection.
5. **Lessons** — Summary of key lessons: seeking refuge, speaking truth to power, common ground between faiths, and the justice of a righteous ruler.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-rendered scenes for each phase with character representations
- Interactive wind navigation (Phase 1) and dialogue choices (Phase 3)
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (RTL support)
- Web Audio API sound effects (no external files)
- High score persistence via localStorage
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Keyboard shortcuts (1-4 for choices, Enter to continue, Escape to close help)
- Responsive design for phone, tablet, and desktop
