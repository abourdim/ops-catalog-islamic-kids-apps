# Messenger Immunity — Diplomatic Protection in Islam

Interactive diplomatic scenario game teaching how the Prophet (peace be upon him) established messenger immunity — the precursor to modern diplomatic immunity conventions.

## Concept

The Prophet established that envoys and messengers cannot be killed or harmed, regardless of their message. This principle predates the Vienna Convention on Diplomatic Relations by over 1300 years. Players face 10 diplomatic scenarios and must choose the correct response.

## The 10 Scenarios

| # | Scenario | Key Principle |
|---|----------|---------------|
| 1 | Musaylimah's Envoys | Envoys protected despite insults |
| 2 | Hudaybiyyah Negotiation | Full diplomatic freedom for negotiators |
| 3 | Letter to Heraclius | Trust in messenger immunity |
| 4 | Spy Among Envoys | Proportionate response |
| 5 | Truce Messenger Under Fire | Ceasefire requests honored |
| 6 | Message to Chosroes | No retaliation against envoys |
| 7 | Hostile Message Received | Messenger separate from message |
| 8 | Safe Passage Request | Universal messenger rights |
| 9 | Female Envoy | Gender-neutral diplomatic immunity |
| 10 | Envoy During Prayer | Worship first, then diplomacy |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Keyboard shortcuts (1-3 for choices, Enter to continue)
- High score persistence via localStorage
- Theme/language/sound preferences persisted
- Scenarios shuffled each playthrough

## Lesson

Islam established diplomatic immunity over 1400 years ago. The Prophet's principle that 'envoys are not killed' laid the foundation for modern international law.
