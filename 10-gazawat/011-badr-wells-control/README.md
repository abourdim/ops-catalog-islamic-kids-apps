# Wells of Badr — Control the water, control the battle

A canvas-based strategy game for Muslim kids about the Battle of Badr's well-control strategy.

## Game Overview

Players learn about Hubab ibn al-Mundhir's historic advice to the Prophet Muhammad (peace be upon him) before the Battle of Badr: move to the nearest wells, secure them for the Muslim army, and block the rest with sand so Quraysh cannot access water.

## How to Play

1. Watch the **shura dialogue** — Hubab asks if the position is revelation or strategy, and the Prophet (peace be upon him) says strategy. Hubab advises moving to the wells.
2. **Drag scout units** from the green camp (south) to blue wells to secure them.
3. **Click secured wells** to fill their water reservoirs.
4. **Click neutral wells** in the north half to block them with sand (Hubab's strategy).
5. Secure or block all 5 wells before the Quraysh column reaches the valley.
6. Enemy units without water weaken over time (thirst meter rises).

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `1`-`5` | Dispatch scout to well / fill secured well |
| `B` | Block nearest neutral enemy-side well with sand |
| `Enter` | Start / New Game |
| `Escape` | Close help sidebar |

## Difficulty Levels

- **Easy** — 90 seconds, slow Quraysh advance
- **Medium** — 60 seconds, moderate advance
- **Hard** — 40 seconds, fast advance

## Lessons

- **Shura (consultation)** — leaders consult their companions
- **Accepting good advice** — regardless of rank
- **Strategic resource control** — water management decided the battle

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based rendering with touch and mouse support
- 8 CSS themes (Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand)
- 3 languages (EN / FR / AR with RTL support)
- Sound effects via Web Audio API (no audio files)
- High score persistence via localStorage
- Theme, language, and sound preferences persisted
- Sidebar help panel with FAQ, How-To, and Wiki tabs
