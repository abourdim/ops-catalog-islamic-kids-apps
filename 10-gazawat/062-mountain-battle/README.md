# Mountain Battle — Elevation Advantage

Interactive canvas strategy game where players use mountain terrain to defend against enemy waves, inspired by the Battle of Uhud.

## Concept

Use elevation advantages in mountain terrain. Position archers on ridges for bonus damage, block narrow passes with infantry, and set boulder traps that roll downhill. Inspired by the strategic positioning at the Battle of Uhud (3 AH).

## Gameplay

- Place archers on ridges (50% elevation damage bonus on high ground)
- Position infantry at narrow mountain passes as blockers
- Set boulder traps that deal 80 area damage when triggered
- Procedurally generated mountain terrain each game
- Survive 5 waves of increasingly difficult enemies

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted
- Procedural mountain terrain generation

## Lesson

The Battle of Uhud taught the critical importance of holding elevated positions. When the archers abandoned their high ground, the battle's outcome changed dramatically — a lesson in discipline and strategic terrain use.
