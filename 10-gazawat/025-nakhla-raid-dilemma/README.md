# Nakhla Raid — The First Armed Encounter

Interactive moral dilemma game for Muslim kids about the Nakhla Raid (Sariyyat Nakhla), the first armed encounter in Islamic history.

## What It Teaches

- The historical context of the Nakhla raid (2 AH / 624 CE)
- The concept of sacred months in Islam and pre-Islamic Arabia
- Ethical complexity in real-world decisions
- How divine revelation (Quran 2:217) resolved the controversy
- Rules of engagement and moral reasoning

## How It Works

The game unfolds in 6 interactive phases:

| Phase | Content |
|-------|---------|
| 1 | Canvas scene — 12-man scout party led by Abdullah ibn Jahsh sent toward Mecca |
| 2 | They spot a Quraysh trade caravan at Nakhla on the last day of Rajab |
| 3 | Interactive decision — Attack now? Wait? Or observe only? |
| 4 | What actually happened — the attack, one killed, two captured, goods seized |
| 5 | Consequences — Quraysh outrage, Prophet's anger, then Quran 2:217 revealed |
| 6 | Analysis — compares kid's choice to history, discusses ethical complexity |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes (Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand)
- Trilingual UI (EN / FR / AR with RTL support)
- Canvas-drawn scenes (desert, caravan, battle, revelation)
- Web Audio API sound effects (no external files)
- Keyboard shortcuts (A/B/C or 1/2/3 for choices, Enter/Space/Arrow for next)
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Persistent preferences (theme, language, sound, play history)
- Mobile responsive

## Storage

- `wdiy-hs-nakhla` — play count and choice history
- `wdiy-lang` — language preference
- `wdiy-theme` — theme preference
- `wdiy-mute` — sound toggle

## Usage

Open `index.html` in any modern browser. No server required.
