# Janazah Prayer Guide

Step-by-step interactive guide to the funeral (janazah) prayer.

## Concept

An interactive step-by-step guide to the janazah (funeral) prayer. Children learn each takbeer, the associated duas, and the proper sequence of this special prayer.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The janazah prayer is a communal obligation (fard kifayah). Learning it teaches children about caring for the deceased and the Islamic rites of passage.
