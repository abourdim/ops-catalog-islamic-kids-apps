# Salah Positions — Step Through Prayer Positions

Interactive guide to step through the positions of salah with descriptions and transliterations.

## Concept

Learning to pray correctly is essential. This app walks children through each position of salah in order, with descriptions of what to say and do at each step.

## Positions

| # | Position | Arabic | Description |
|---|----------|--------|-------------|
| 1 | Qiyam | القيام | Standing upright facing the Qiblah |
| 2 | Takbir | التكبير | Raising hands and saying Allahu Akbar |
| 3 | Qira'ah | القراءة | Reciting Al-Fatiha and a surah |
| 4 | Ruku | الركوع | Bowing with hands on knees |
| 5 | I'tidal | الاعتدال | Rising from bowing |
| 6 | Sujud | السجود | Prostrating with forehead on ground |
| 7 | Juloos | الجلوس | Sitting between two prostrations |
| 8 | Tashahhud | التشهد | Final sitting with finger pointing |
| 9 | Tasleem | التسليم | Turning head right and left to end |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Step-by-step navigation with descriptions
- Quiz mode to sequence positions correctly
- High score persistence via localStorage

## Lesson

Each position in salah has deep meaning. The physical movements reflect the soul's submission to Allah, from standing in humility to prostrating in complete surrender.
