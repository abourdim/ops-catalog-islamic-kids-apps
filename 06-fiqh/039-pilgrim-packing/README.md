# Pilgrim Packing

Pack a bag for Hajj/Umrah. Drag items into suitcase. Weight limit. Essential vs optional.

## Concept

A packing game where children prepare a bag for Hajj/Umrah by dragging items into a suitcase with a weight limit. Items are categorized as essential, recommended, or optional.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Preparing for Hajj teaches planning and prioritizing what matters. Pilgrims travel light, focusing on spiritual readiness over material comfort.
