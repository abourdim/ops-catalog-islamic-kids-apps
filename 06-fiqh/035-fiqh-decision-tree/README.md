# Fiqh Decision Tree

Interactive flowchart for fiqh rulings. Navigate branching decisions on Islamic jurisprudence topics.

## Concept

An interactive decision tree where children navigate fiqh rulings by answering yes/no questions. Topics include prayer validity, fasting rules, and halal/haram food.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Fiqh teaches us how to apply Islamic law in daily life. Decision trees help children understand the logical structure of Islamic rulings.
