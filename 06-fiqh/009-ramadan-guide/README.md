# Ramadan Guide

**Everything about the blessed month**

An interactive Ramadan quiz app for Muslim kids covering all aspects of the blessed month through fun multiple-choice questions with detailed explanations and Quran/Hadith references.

## Features

- **30+ questions** across 10 categories
- **3 difficulty levels**: Easy (10 basic), Medium (20 mixed), Hard (30+ detailed)
- **Detailed explanations** with Quran ayat and Hadith references after each answer
- **8 CSS themes**: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- **Trilingual**: English, French, Arabic (RTL)
- **Sound effects** via Web Audio API (no external files)
- **High score** persistence via localStorage
- **Keyboard shortcuts**: 1-4 for answers, Enter to start, Escape to close help
- **Sidebar help** with FAQ, How-To, and Wiki tabs
- **Fully offline** — single HTML file, zero dependencies

## Topics Covered

| Category | Examples |
|---|---|
| Fasting Rules | What breaks the fast, what doesn't, who is exempt, suhoor/iftar sunnah |
| Taraweeh | Rakahs, timing, sunnah practices |
| Laylat al-Qadr | When to seek it, signs, dua, reward |
| Zakat al-Fitr | Timing, amount, recipients |
| Eid al-Fitr | Sunnah acts, prayer, takbirat |
| Itikaf | Definition, location, rules, duration |
| Quran in Ramadan | Jibreel's review, extra reward |
| Charity | Multiplied reward, feeding fasting people |
| Good Deeds | Avoiding bad habits, multiplied reward |
| History | When fasting was prescribed, Battle of Badr |

## Usage

Open `index.html` in any modern browser. No server or internet required.

## Storage Keys

- `wdiy-hs-ramadan-guide` — High score
- `wdiy-lang` — Language preference
- `wdiy-theme` — Theme preference
- `wdiy-mute` — Sound mute state
