# Friday Prayer

Learn about Jumuah prayer etiquette and obligations.

## Concept

Interactive quiz covering Friday prayer rulings: obligation, rakaat count, ghusl, Surah Al-Kahf, and the special hour of acceptance.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz on Jumuah rules and etiquette
- High score persistence via localStorage

## Lesson

Friday is the best day of the week in Islam. The Prophet called it the master of days, containing a special hour when dua is accepted.
