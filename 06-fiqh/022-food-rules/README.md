# Food Rules

Sort foods into halal, haram categories and learn eating etiquette.

## Concept

Interactive quiz on Islamic food rulings: halal meat, forbidden pork, seafood, alcohol prohibition, and the Sunnah of saying Bismillah.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz on halal/haram food categories
- High score persistence via localStorage

## Lesson

Islam provides clear guidelines on food to protect health and maintain spiritual purity. Saying Bismillah makes eating an act of worship.
