# Nikah Ceremony Planner

Learn about Islamic marriage ceremony steps. Arrange the events in correct order.

## Concept

An ordering game where children learn about the Islamic marriage ceremony by arranging its steps (istikhara, mahr, wali, khutbah, aqd, walimah) in the correct sequence.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Marriage is half of the deen. Understanding the nikah ceremony teaches children about this important Islamic institution and its beautiful traditions.
