# Halal or Haram? — Islamic Sorting Game

**Sort what is permissible in Islam**

An interactive game for Muslim kids to learn the basics of Halal (permissible) and Haram (forbidden) in Islam. A food, drink, action, or behavior appears and the child sorts it by tapping, clicking, swiping, or using keyboard shortcuts.

## Features

- **40+ items** across foods, drinks, actions, and behaviors
- **Islamic explanations** with Quran and Hadith references after each answer
- **3 difficulty levels**: Easy (10 obvious items), Medium (15 with trickier items), Hard (20 with edge cases)
- **Two big sort buttons**: green Halal / red Haram
- **Swipe support**: swipe right for Halal, left for Haram on touch devices
- **Keyboard shortcuts**: H = Haram, L = Halal, Arrow keys, Enter = New Game
- **8 CSS themes**: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- **3 languages**: English, French, Arabic (with RTL support)
- **Sound effects** via Web Audio API (no files needed)
- **High score** persistence via localStorage
- **Theme/language/sound** preferences persisted across sessions
- **Splash screen** with Bismillah
- **Sidebar help** panel with FAQ, How-To, and Wiki tabs
- **Single HTML file**, zero dependencies, fully offline

## Controls

| Input | Action |
|-------|--------|
| Tap green button | Halal |
| Tap red button | Haram |
| Swipe right | Halal |
| Swipe left | Haram |
| `L` key | Halal |
| `H` key | Haram |
| Arrow Right | Halal |
| Arrow Left | Haram |
| `Enter` | Start / New Game |
| `Escape` | Close help panel |
