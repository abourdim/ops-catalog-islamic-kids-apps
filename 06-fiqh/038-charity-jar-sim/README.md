# Charity Jar Simulator

Virtual charity jar. Add coins, set goals, and track your giving. Sadaqah tracker.

## Concept

A virtual sadaqah (charity) jar where children add coins, set savings goals, and track their charitable giving over time. The jar fills up visually as they add more.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Sadaqah (voluntary charity) is beloved to Allah. Even a smile is charity. This jar teaches children the joy of giving and the habit of regular generosity.
