# Prayer Rug Designer

Canvas tool to design prayer rug patterns with Islamic geometric art.

## Concept

A creative canvas tool where children design prayer rug patterns using Islamic geometric shapes, colors, and symmetry. Draw stars, hexagons, and arabesque patterns.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The prayer rug is a personal space for connecting with Allah. Designing one teaches children about Islamic geometric art and the beauty of sacred spaces.
