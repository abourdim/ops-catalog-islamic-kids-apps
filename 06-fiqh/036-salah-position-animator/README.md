# Salah Position Animator

Animated stick figure performing salah positions. Control speed and loop sections.

## Concept

An animated stick figure that demonstrates all salah positions with smooth transitions. Children can control the speed, pause, and loop specific positions.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Salah is the second pillar of Islam. Seeing the positions animated helps children learn the correct physical movements of prayer.
