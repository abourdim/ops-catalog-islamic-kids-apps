# Mosque Etiquette Simulator

Navigate a virtual mosque and learn correct behavior at each area.

## Concept

An interactive virtual mosque where children explore different areas (entrance, shoe rack, prayer hall, mihrab) and learn the correct etiquette for each location.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The mosque is the house of Allah. Learning proper etiquette teaches children respect for sacred spaces and the Sunnah of visiting the masjid.
