# Salah Compass

Find the Qibla direction with an interactive compass simulator. Rotate to align with Mecca.

## Concept

An interactive Qibla compass simulator. The player is placed in a random city and must rotate the compass needle to point toward Mecca (the Ka'bah). The closer the alignment, the higher the score.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- localStorage persistence
- Interactive canvas/drag-and-drop interface

## Lesson

Muslims pray facing the Ka'bah in Mecca. Finding the Qibla teaches us about geography, the unity of the Muslim ummah, and the importance of direction in worship.
