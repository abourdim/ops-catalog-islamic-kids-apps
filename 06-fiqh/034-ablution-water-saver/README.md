# Ablution Water Saver

Game about using minimal water for wudu. Control the tap, measure usage, and optimize.

## Concept

A water conservation game where children must perform wudu using as little water as possible. A tap flows water and they must time it correctly for each step.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The Prophet (peace be upon him) used only about 750mL for wudu. This teaches water conservation, a key Islamic value of not being wasteful.
