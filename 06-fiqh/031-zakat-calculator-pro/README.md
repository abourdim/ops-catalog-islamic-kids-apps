# Zakat Calculator Pro

Advanced zakat calculator. Input your assets and calculate the amount due.

## Concept

An interactive zakat calculator where children input different types of assets (gold, silver, cash, investments) and the app calculates the zakat due at 2.5%.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Zakat purifies our wealth and helps those in need. Learning to calculate zakat teaches children about financial responsibility and generosity in Islam.
