# Zakat Types

Learn different types of zakat and who receives it.

## Concept

Interactive quiz covering types of zakat (wealth, fitr, gold, crops, livestock, trade goods), rates, nisab thresholds, and the 8 categories of recipients from Quran 9:60.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz on zakat types, rates, and recipients
- High score persistence via localStorage

## Lesson

Zakat purifies wealth and builds social solidarity, ensuring blessings are shared with those in need.
