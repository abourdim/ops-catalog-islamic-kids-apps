# Hajj Map Navigator

Navigate Hajj landmarks on an interactive map. Visit Mina, Arafat, Muzdalifah and more.

## Concept

An interactive map of Hajj landmarks. Players click on locations in the correct order of Hajj rituals, learning about each sacred site along the way.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Hajj is the fifth pillar of Islam. Understanding its geography helps children appreciate this profound journey of faith that millions undertake each year.
