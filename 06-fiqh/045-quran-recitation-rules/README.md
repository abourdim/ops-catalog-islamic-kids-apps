# Quran Recitation Rules

Interactive tajweed rule visualizer. Color-coded rules with examples.

## Concept

An interactive tajweed visualizer showing color-coded recitation rules. Children click on rules to see examples and hear how they affect pronunciation.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Tajweed ensures the Quran is recited as it was revealed. Learning these rules helps children read the Quran beautifully and correctly.
