# Tayammum Guide

Learn when and how to perform tayammum (dry ablution).

## Concept

Teaches when tayammum is permitted and walks through the steps: intention, Bismillah, striking earth, wiping face and hands.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 6-step tayammum guide
- High score persistence via localStorage

## Lesson

Islam is a practical religion. When water is unavailable or harmful, tayammum provides an alternative for maintaining prayer.
