# Islamic Calendar Maker

Build and explore the Hijri calendar. Mark important Islamic dates and events.

## Concept

An interactive Hijri calendar builder where children explore the 12 Islamic months, learn their names, and mark important dates like Ramadan, Eid, and Hajj.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The Islamic calendar connects Muslims to their history and worship schedule. Knowing the Hijri months helps children anticipate sacred occasions.
