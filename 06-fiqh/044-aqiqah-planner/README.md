# Aqiqah Planner

Plan an aqiqah celebration. Learn traditions, steps, and duas.

## Concept

An interactive planner for the aqiqah celebration (the sacrifice and celebration for a newborn). Children check off tasks and learn about each tradition.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The aqiqah is a Sunnah celebration welcoming a newborn. Learning about it teaches gratitude to Allah for the blessing of children.
