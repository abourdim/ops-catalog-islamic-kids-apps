# Islamic Finance 101

Learn about Islamic finance through a business simulation. No riba, halal investing.

## Concept

A business simulation teaching Islamic finance principles: no riba (interest), halal investing, profit sharing (mudarabah), and ethical trading.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Islamic finance is based on fairness, risk-sharing, and avoiding interest. These principles create a just economic system aligned with Allah's guidance.
