# Hajj Steps

Step-by-step interactive Hajj journey.

## Concept

Walk through the complete Hajj pilgrimage from Ihram to Tawaf al-Wada, learning what happens at each stage with descriptions in three languages.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 12-step guided journey through Hajj
- High score persistence via localStorage

## Lesson

Hajj is the fifth pillar of Islam, uniting millions in worship. Each ritual carries deep spiritual meaning connecting to the legacy of Ibrahim.
