# Fiqh Scenario Solver

Complex fiqh scenarios with branching decision paths and consequences.

## Concept

Complex real-life fiqh scenarios where children must make decisions and see the consequences. Each scenario has multiple choice paths leading to different outcomes.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Applying fiqh to real-life situations is the essence of Islamic jurisprudence. These scenarios teach children to think critically about everyday decisions.
