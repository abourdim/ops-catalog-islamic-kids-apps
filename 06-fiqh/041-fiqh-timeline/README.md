# Fiqh Timeline

Timeline of the development of Islamic jurisprudence. Schools, scholars, key texts.

## Concept

An interactive timeline showing the development of Islamic jurisprudence from the time of the Prophet through the four great schools of thought and beyond.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Understanding the history of fiqh helps children appreciate how Islamic scholars worked to preserve and apply the teachings of the Quran and Sunnah through the centuries.
