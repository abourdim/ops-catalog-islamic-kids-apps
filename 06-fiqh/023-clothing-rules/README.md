# Clothing Rules

Learn about Islamic dress code and modesty principles.

## Concept

Quiz covering modesty as a branch of faith, silk and gold rulings for men, and the emphasis on cleanliness in dress.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz on Islamic dress code
- High score persistence via localStorage

## Lesson

Islamic clothing guidelines promote dignity, modesty, and cleanliness while allowing cultural expression within Sharia boundaries.
