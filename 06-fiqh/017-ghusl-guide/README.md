# Ghusl Guide

Learn the steps of ghusl (ritual bath) interactively.

## Concept

Step through the complete ghusl process: intention, Bismillah, washing hands, private parts, wudu, head, body, and feet.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 8-step guided ghusl process
- High score persistence via localStorage

## Lesson

Ghusl is required after certain states of impurity. Knowing how to perform it correctly ensures valid prayer and worship.
