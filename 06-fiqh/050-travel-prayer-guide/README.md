# Travel Prayer Guide

Interactive guide for combining and shortening prayers while traveling.

## Concept

An interactive guide teaching the rules of shortening (qasr) and combining (jam) prayers while traveling. Set your journey distance and duration to see which concessions apply.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Allah has made the religion easy. Travel prayer concessions are a mercy that teaches children about the flexibility and compassion built into Islamic law.
