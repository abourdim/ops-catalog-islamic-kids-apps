# Inheritance Basics

Simple introduction to Islamic inheritance shares.

## Concept

Learn that Allah prescribed inheritance in the Quran, the one-third limit for wills, and the order of payments from an estate.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz on inheritance fundamentals
- High score persistence via localStorage

## Lesson

Islamic inheritance ensures fair distribution of wealth according to divine wisdom, protecting the rights of all family members.
