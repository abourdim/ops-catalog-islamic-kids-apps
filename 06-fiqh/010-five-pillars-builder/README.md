# Five Pillars Builder

Interactive builder for the 5 pillars of Islam — place each pillar in the correct order and learn its meaning.

## Concept

The five pillars of Islam are the foundation of every Muslim's life. Players build the pillars by placing each one in its correct position (1-5), learning about each pillar as they go.

## The 5 Pillars

| # | Pillar | Arabic | Description |
|---|--------|--------|-------------|
| 1 | Shahada | الشهادة | Testimony of faith — no god but Allah, Muhammad is His messenger |
| 2 | Salah | الصلاة | Five daily prayers at specific times |
| 3 | Zakat | الزكاة | Obligatory charity — 2.5% of saved wealth annually |
| 4 | Sawm | الصيام | Fasting during Ramadan from dawn to sunset |
| 5 | Hajj | الحج | Pilgrimage to Mecca at least once if able |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Click-to-place pillar building mechanic
- Info cards with descriptions for each pillar
- High score persistence via localStorage

## Lesson

The five pillars are the core acts of worship in Islam. Each pillar builds upon the previous one, starting with faith (Shahada) and culminating in the communal pilgrimage (Hajj).
