# Fasting Rules

Interactive guide to Ramadan fasting rules and exceptions.

## Concept

Children answer questions about fasting rules: what breaks the fast, what is allowed, who is excused. Each answer reveals the ruling with explanation.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz format with 8 fasting scenarios
- High score persistence via localStorage

## Lesson

Fasting teaches self-discipline, empathy for the hungry, and gratitude. Islam provides merciful exceptions.
