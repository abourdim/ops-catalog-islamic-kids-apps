# Mosque Architect

Design beautiful mosques with drag-and-drop architectural elements. Place domes, minarets, mihrab, and more.

## Concept

A creative mosque design tool where children can drag and drop Islamic architectural elements onto a canvas to build their dream mosque. Elements include domes, minarets, mihrab, minbar, arches, and courtyards.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- localStorage persistence
- Interactive canvas/drag-and-drop interface

## Lesson

Mosques are the houses of Allah. Learning about mosque architecture connects children with Islamic heritage and the beauty of sacred spaces designed for worship.
