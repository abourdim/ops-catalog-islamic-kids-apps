# Sadaqah Project Builder

Plan a charity project. Set goals, budget, timeline, and beneficiaries.

## Concept

A project planning tool for charity. Children design a sadaqah project by setting goals, choosing beneficiaries, allocating budget, and creating a timeline.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Planning charity projects teaches organization and empathy. The Prophet ﷺ encouraged ongoing charity (sadaqah jariyah) that benefits people continuously.
