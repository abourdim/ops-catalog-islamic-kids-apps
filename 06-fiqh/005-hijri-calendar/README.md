# Hijri Calendar

Learn the Islamic months and events.

## What It Teaches

- The 12 months of the Hijri (Islamic) calendar
- Arabic names, English transliterations, and month numbers
- Important Islamic events and which months they fall in
- The significance of each month and event

## Islamic Events Covered

- Hijri New Year (1 Muharram)
- Ashura (10 Muharram)
- Mawlid an-Nabi (12 Rabi al-Awwal)
- Isra wal Miraj (27 Rajab)
- Shaban Fasting (Mid-Shaban)
- Ramadan Begins (1 Ramadan)
- Laylat al-Qadr (27 Ramadan)
- Eid al-Fitr (1 Shawwal)
- Day of Arafah (9 Dhul Hijjah)
- Eid al-Adha (10 Dhul Hijjah)

## Game Modes

- **Easy** — 6 major months (Muharram, Rabi al-Awwal, Rajab, Ramadan, Shawwal, Dhul Hijjah), 8 questions
- **Medium** — All 12 months, 10 questions
- **Hard** — Months + Islamic events mixed, 12 questions

## How It Works

1. A Hijri month name in Arabic is shown — pick the correct English name and number
2. (Hard mode) An Islamic event is shown — pick which Hijri month it falls in
3. After each correct answer, the significance of the month or event is displayed
4. Multiple choice with 4 options per question

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes (Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand)
- Trilingual UI (English, French, Arabic with RTL)
- Sound effects via Web Audio API
- High score persistence via localStorage
- Keyboard shortcuts (1-4 for answers, Enter to start)
- Sidebar help with FAQ, How-To, and Wiki tabs

## Storage

- `wdiy-hs-hijri-calendar` — high score (percentage)
- `wdiy-lang` — language preference
- `wdiy-theme` — theme preference
- `wdiy-mute` — sound mute state
