# Islamic Diet Planner

Plan halal meals for a week. Drag food items and check their halal status.

## Concept

A weekly meal planner where children drag food items to daily meal slots. Each food item has a halal status (halal, doubtful, or haram) that teaches dietary rules.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Islam teaches us to eat what is halal (permitted) and tayyib (wholesome). This planner helps children learn which foods are halal and how to make healthy choices.
