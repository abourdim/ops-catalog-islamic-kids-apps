# Moon Sighting Simulator

Simulate crescent moon sighting for Ramadan. Telescope view with horizon scanning.

## Concept

A moon sighting simulation where children scan the horizon with a virtual telescope to spot the crescent moon that marks the beginning of Ramadan or Eid.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Moon sighting connects Muslims to the lunar calendar established by Allah. It teaches observation skills and the communal excitement of starting Ramadan.
