# Build Nuh's Ark

Build Nuh's ark step by step — gathering wood, constructing the frame, loading animals.

## Concept

Step-by-step interactive construction of Nuh's ark.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects
- localStorage persistence


## Lesson

Trust in Allah even when mocked. Patient work guided by faith achieves the impossible.
