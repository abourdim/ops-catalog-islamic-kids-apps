# Quran Numbers — Quiz About Numbers in the Quran

Quiz game about significant numbers mentioned in the Quran and Islamic tradition.

## Concept

Players answer questions about numbers in the Quran and Islam: How many heavens? How many months? How long did the People of the Cave sleep? Each answer includes a Quranic reference and explanation.

## Sample Questions

- How many heavens did Allah create? (7 — Al-Mulk 67:3)
- Night of Qadr is better than how many months? (1000 — Al-Qadr 97:3)
- How many years did the People of the Cave sleep? (309 — Al-Kahf 18:25)
- How many springs gushed when Musa struck the rock? (12 — Al-Baqarah 2:60)

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 14 questions in pool, 10 per round
- Quranic references with each answer
- Score tracking and high scores via localStorage

## Lesson

Numbers in the Quran carry deep significance. Learning them builds familiarity with key Quranic facts and references.
