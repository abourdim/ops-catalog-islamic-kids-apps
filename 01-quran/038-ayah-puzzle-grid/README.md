# Ayah Puzzle Grid

Sliding tile puzzle where pieces are words of an ayah. Solve the puzzle to reveal the complete verse.

## Concept

Classic 4x4 sliding tile puzzle adapted for Quran learning. Each tile contains a word from a verse. Slide tiles to arrange them in the correct order and reveal the complete ayah.

## Features

- Single HTML file, zero dependencies, fully offline
- Sliding tile puzzle mechanics with smooth animations
- Multiple verses with increasing difficulty
- Move counter and timer
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
