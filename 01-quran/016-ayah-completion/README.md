# Ayah Completion — Complete the Missing Word

Quiz game where players fill in the missing Arabic word from famous Quranic ayahs.

## Concept

A famous ayah is displayed in Arabic with one key word replaced by a blank. The player chooses the correct word from 4 options. After answering, the complete ayah is shown with the correct word highlighted.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 15 famous ayahs in the pool
- 10 questions per round, shuffled
- Beautiful Arabic typography with highlighted blanks
- Score tracking and high scores via localStorage

## Lesson

This game reinforces Quran memorization by testing recall of specific words within famous verses, building deeper familiarity with the Quranic text.
