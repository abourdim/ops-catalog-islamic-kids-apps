# Surah Music Box

Each surah represented as a unique tonal pattern. Tap surahs to hear their rhythmic tajweed pattern visualization using Web Audio API tones.

## Concept

Children explore 114 surahs as melodic patterns (non-musical, using pure tones). Each surah has a unique rhythmic signature based on its verse count and syllable patterns. Visual waveform animations accompany each pattern.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based waveform visualization
- Unique tonal patterns for each surah based on ayah count
- Tap/click surahs to play their pattern
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects
- localStorage persistence
