# Quran Verse Builder

Drag-and-drop Arabic word tiles to reconstruct ayahs. Words scatter and child rebuilds them in correct order with progressive difficulty.

## Concept

Children learn Quran verses by reconstructing them from scattered word tiles. Words from a verse are shuffled and displayed as draggable tiles. The child must arrange them in the correct order. Difficulty increases with longer verses.

## Features

- Single HTML file, zero dependencies, fully offline
- Drag-and-drop word tiles with touch support
- Progressive difficulty (short to long verses)
- Score tracking and timer
- 8 CSS themes
- Trilingual: EN/FR/AR with RTL
- Splash screen with Bismillah
- Sidebar help panel
- Web Audio API sounds
- localStorage high scores
