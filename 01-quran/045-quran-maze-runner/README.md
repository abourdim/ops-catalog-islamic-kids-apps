# Quran Maze Runner

Navigate mazes where correct turns require Quran knowledge. Wrong turns = dead ends with learning moments.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based maze generation and navigation
- Knowledge-based path decisions
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
