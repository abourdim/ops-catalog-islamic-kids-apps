# Surah Color Painter

Each surah has a color palette based on its themes. Paint canvas scenes inspired by surah meanings.

## Concept

Children explore surahs through color. Each surah is assigned a thematic palette. Kids paint scenes on a canvas using those colors, connecting visual art to Quran themes.

## Features

- Single HTML file, zero dependencies, fully offline
- HTML5 Canvas painting with themed color palettes
- Multiple brush sizes and styles
- Surah-inspired color schemes
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
