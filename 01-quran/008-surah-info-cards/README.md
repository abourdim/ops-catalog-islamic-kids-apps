# Surah Info Cards — Browse All 114 Surahs

Interactive catalog of all 114 surahs of the Quran with detailed info cards showing revelation place, verse count, and key themes.

## Concept

Browse beautiful cards for each of the 114 surahs. Each card displays the surah number, name (English and Arabic), whether it is Makki or Madani, verse count, and a summary of key themes. Click any card to expand and learn more.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Search by surah name or number
- Filter by Makki or Madani
- Expandable cards with theme details
- All 114 surahs included

## Lesson

Learning about each surah helps build a deeper connection with the Quran, understanding its structure, themes, and the context in which each chapter was revealed.
