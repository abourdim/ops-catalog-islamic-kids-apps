# Tajweed Practice — Color-Coded Tajweed Rules

Interactive tajweed learning app with color-coded examples from the Quran for 7 key tajweed rules.

## Concept

Each tajweed rule is presented with its own color, a clear explanation, and a real Quranic example where the relevant letters are highlighted in that color — matching the color-coding system used in printed Tajweed Mushafs.

## Rules Covered

1. Ghunnah (Nasalization) - Red
2. Ikhfa (Concealment) - Orange
3. Idgham (Merging) - Green
4. Iqlab (Conversion) - Blue
5. Izhar (Clarity) - Purple
6. Madd (Elongation) - Coral
7. Qalqalah (Echo) - Yellow

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Color-coded tajweed highlights in Arabic text
- Expandable cards with examples
- Quranic references for each example
- Preferences persisted via localStorage

## Lesson

Tajweed is essential for proper Quran recitation. Learning the rules early helps children develop beautiful and accurate recitation habits.
