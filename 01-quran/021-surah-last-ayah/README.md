# Surah Last Ayah — Match Surahs to Closing Verses

Quiz game where players identify surahs from their closing/last verses displayed in Arabic.

## Concept

The last verse of a surah is displayed in Arabic, and the player must choose the correct surah name from 4 multiple-choice options. Each round has 10 questions from a pool of 16 surahs with distinctive closing verses.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 16 surahs in pool, 10 per round
- Keyboard shortcuts (1-4)
- Score tracking and high scores via localStorage

## Lesson

Recognizing surahs by their closing verses strengthens memorization and familiarity with how each surah ends.
