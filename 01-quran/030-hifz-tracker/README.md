# Hifz Tracker — Track Memorization Progress

Interactive Quran memorization tracker covering all 114 surahs with spaced repetition status tracking.

## Concept

Track your Quran memorization journey surah by surah. Click any surah to cycle through 4 states: Not Started, Learning, Reviewing, and Memorized. See overall progress with stats and a progress bar. All progress is saved locally.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- All 114 surahs with verse counts
- 4-state tracking: Not Started, Learning, Reviewing, Memorized
- Color-coded status indicators
- Overall progress bar and statistics
- Filter by status
- Reset option with confirmation
- All progress persisted via localStorage

## Lesson

Memorizing the Quran (hifz) is one of the greatest acts of worship. This tracker helps children set goals, track progress, and stay motivated on their memorization journey.
