# Quran Stories

**Discover the stories of the Quran**

An interactive quiz game for Muslim kids where they identify the correct surah or prophet associated with a scene from the Quran. After each correct answer, the game reveals the surah reference, a brief retelling, and the moral lesson.

## Features

- **22 Quran stories** covering prophets, surahs, and historical events
- **3 difficulty levels**: Easy (10 famous stories), Medium (15), Hard (20+)
- **Educational feedback**: surah reference, retelling, and lesson after each answer
- **8 CSS themes**: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- **Trilingual**: English, French, Arabic (with RTL support)
- **Sound effects**: Web Audio API (no external files)
- **Keyboard shortcuts**: 1-4 for answers, Enter to start, Escape to close help
- **High score persistence** via localStorage
- **Sidebar help panel** with FAQ, How-To, and Wiki tabs
- **Fully offline**: single HTML file, zero dependencies
