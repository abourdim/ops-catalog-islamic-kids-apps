# Ayah of the Day — Daily Quranic Inspiration

Daily random ayah display with Arabic text, translation, and brief tafsir explanation.

## Concept

Each day presents a different ayah from the Quran based on the date. Users see the Arabic text, its translation, and a brief tafsir (explanation). They can save favorites and request new random ayahs anytime.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Date-based daily ayah with consistent seed
- Random ayah refresh button
- Save to favorites with localStorage
- Beautiful Arabic typography

## Lesson

Daily reflection on Quranic verses builds a deeper connection with Allah's words and helps internalize their meanings.
