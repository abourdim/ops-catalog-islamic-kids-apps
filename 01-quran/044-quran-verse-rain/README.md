# Quran Verse Rain

Falling Arabic words (like Tetris). Catch words in correct order to form ayahs. Speed increases.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based falling word game
- Catch words in correct order to form verses
- Progressive speed increase
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
