# Quran Arabic Root — Explore Root Words and Derivatives

Interactive explorer for Arabic root words and their derivatives found in the Quran.

## Concept

Arabic words are built from 3-letter roots. This app shows 15 important roots used in the Quran with their derivatives. Click a root to see all the words that come from it — understanding one root unlocks understanding many words.

## Roots Included

K-T-B (write), Ain-L-M (know), R-H-M (mercy), H-M-D (praise), A-M-N (believe), S-L-H (righteous), S-B-R (patience), Sh-K-R (gratitude), Q-R-A (read), S-L-W (pray), H-D-Y (guide), N-S-R (help), H-Q-Q (truth), Dh-K-R (remember), J-N-N (conceal)

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 15 root words with 4-6 derivatives each
- Search by root or meaning
- Expandable cards showing word families
- Preferences persisted via localStorage

## Lesson

The Arabic root system is one of the most logical language structures in the world. Understanding roots makes Quranic Arabic accessible and reveals the deep connections between related concepts.
