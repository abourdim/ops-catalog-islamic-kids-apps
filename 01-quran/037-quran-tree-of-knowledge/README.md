# Quran Tree of Knowledge

Growing tree visualization. Each branch is a Quran topic. Click leaves to explore ayahs. Tree grows as you learn.

## Concept

An interactive tree that grows as children explore Quran topics. Branches represent major themes, leaves are individual ayahs. The tree visually grows with each verse explored.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based animated growing tree
- Interactive branches and leaves
- Topic-based organization of Quran content
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
