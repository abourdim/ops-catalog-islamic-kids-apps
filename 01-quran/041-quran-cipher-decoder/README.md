# Quran Cipher Decoder

Decode encrypted ayahs using letter substitution. Teaches Arabic letters while solving puzzles.

## Concept

Ayahs are encoded with a substitution cipher. Children decode the message letter by letter, learning Arabic character recognition while solving the cryptographic puzzle.

## Features

- Single HTML file, zero dependencies, fully offline
- Substitution cipher puzzles with Arabic letters
- Hint system and progressive difficulty
- Letter frequency analysis helper
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
