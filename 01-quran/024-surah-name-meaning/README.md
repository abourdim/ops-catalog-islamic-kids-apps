# Surah Name Meaning — Match Surah Names to English Meanings

Quiz game where players match Arabic surah names to their English (or French) meanings.

## Concept

A surah name is shown in Arabic with its transliteration, and the player picks the correct meaning from 4 options. Pool of 42 surahs with distinctive names, 10 per round.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 42 surahs in pool, 10 per round
- Keyboard shortcuts (1-4)
- Score tracking and high scores via localStorage

## Lesson

Knowing what surah names mean deepens connection with the Quran and makes it easier to remember which surah covers which topic.
