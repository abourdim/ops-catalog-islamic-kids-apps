# Juz Navigator — Explore the 30 Parts of the Quran

Interactive navigator for all 30 juz (parts) of the Quran, showing which surahs and verses are in each juz.

## Concept

The Quran is divided into 30 equal parts called juz (ajza). This tool lets kids click any juz number and see its contents — which surahs it contains and the verse ranges. Each juz also shows its traditional Arabic name.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Clickable grid of all 30 juz
- Detailed surah and verse listings per juz
- Preferences persisted via localStorage

## Lesson

Understanding the juz system helps with Quran memorization and reading goals, especially completing the Quran during Ramadan (one juz per day).
