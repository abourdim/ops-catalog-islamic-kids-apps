# Quran Constellation Map

Night sky visualization where each surah is a star. Constellations form by theme. Click stars to explore surahs.

## Concept

An interactive star map where 114 stars represent 114 surahs. Stars are grouped into constellations by theme (faith, stories, law, etc.). Click any star to learn about its surah.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based starfield with twinkling animation
- Constellation lines connecting themed surahs
- Click stars to reveal surah information
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
