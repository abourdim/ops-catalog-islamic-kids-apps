# Makki-Madani Sort — Sort Surahs by Revelation Place

Interactive sorting game where players categorize surahs as Makki (revealed in Mecca) or Madani (revealed in Medina).

## Concept

A surah card appears showing the name in English and Arabic. The player must decide: was it revealed in Mecca (Makki) or Medina (Madani)? After each answer, a helpful hint explains why, teaching the characteristics of each category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 23 surahs in the pool, 12 per round
- Keyboard shortcuts (1 = Makki, 2 = Madani)
- Educational hints after each answer
- Score tracking and high scores via localStorage

## Lesson

Understanding the Makki-Madani classification helps appreciate the context of revelation and the progressive nature of Quranic guidance.
