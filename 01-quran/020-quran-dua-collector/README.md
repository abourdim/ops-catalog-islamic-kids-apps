# Quran Dua Collector — Collect and Memorize Quranic Duas

Interactive dua collection app featuring beautiful supplications found in the Quran with save-to-collection functionality.

## Concept

Browse 12 beautiful duas from the Quran with Arabic text, translation, reference, and attribution (which prophet or group made this dua). Save your favorites to build a personal dua collection stored locally.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 12 Quranic duas with full Arabic text
- Save/unsave to personal collection
- Filter to view only saved duas
- Collection persisted via localStorage

## Lesson

The Quran contains the most beautiful and comprehensive supplications. Learning these duas teaches children how to call upon Allah in every situation.
