# Surah Rhythm Tapper

Tap along to the rhythm of Quran recitation patterns. Visual beat indicators. Learn tajweed through rhythm.

## Concept

Children learn tajweed rhythms by tapping along to visual beat patterns. Each surah has characteristic rhythmic patterns that children match by tapping in time.

## Features

- Single HTML file, zero dependencies, fully offline
- Rhythm-based tapping gameplay
- Visual beat indicators with timing feedback
- Multiple difficulty levels
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
