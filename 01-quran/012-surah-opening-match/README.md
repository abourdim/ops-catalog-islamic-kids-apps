# Surah Opening Match — Match Surahs to First Verses

Quiz game where players identify surahs from their opening verses displayed in Arabic.

## Concept

The opening verse of a surah is displayed in Arabic, and the player must choose the correct surah name from 4 multiple-choice options. Each round has 10 questions drawn from a pool of 33 surahs with distinctive openings.

## The Quiz

Players see famous openings like:
- "Al-Hamdu lillahi Rabbil 'Alamin" (Al-Fatihah)
- "Iqra bismi Rabbik alladhi khalaq" (Al-Alaq)
- "Qul Huwa Allahu Ahad" (Al-Ikhlas)
- And many more distinctive surah openings

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 33 surahs in the question pool
- 10 questions per round, shuffled each time
- Score tracking with progress bar
- High score persistence via localStorage

## Lesson

Recognizing surahs by their opening verses strengthens Quran familiarity and helps with memorization and recitation.
