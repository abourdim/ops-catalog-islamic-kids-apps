# Quran Comparison — Compare Similar Ayahs Across Surahs

Interactive tool to compare similar or related ayahs from different surahs side by side with explanations of their differences.

## Concept

8 pairs of similar Quranic verses are displayed side by side. Click each pair to reveal an explanation of the subtle differences between them — why the Quran uses slightly different wording in different contexts and what deeper meaning it conveys.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 8 verse pairs with side-by-side comparison
- Expandable explanations
- Responsive grid layout
- Preferences persisted via localStorage

## Lesson

The Quran's precision in word choice is miraculous. Even when verses seem similar, every difference carries wisdom. This builds appreciation for the linguistic miracle of the Quran.
