# Quran Geography — Map Locations Mentioned in the Quran

Interactive catalog of 14 real-world locations mentioned in the Quran with their Quranic significance and references.

## Concept

Browse cards for places mentioned in the Quran — from Mecca and Medina to Mount Sinai, Badr, Saba, and the Cave of Hira. Each card shows the location name, region, icon, Quranic references, and a description of its significance.

## Locations Included

Mecca, Medina, Mount Sinai, Egypt, Jerusalem, Red Sea, Mount Judi, Iram, Badr, Cave of Hira, Madyan, Saba, Al-Ahqaf, Zamzam Well

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 14 locations with Quranic references
- Expandable cards with detailed descriptions
- Preferences persisted via localStorage

## Lesson

The Quran's stories are rooted in real geography. Knowing where events took place makes Quranic narratives come alive and connects spiritual lessons to the physical world.
