What is a Mind Palace?

The Method of Loci — an ancient memory technique where you place items to remember in mental locations within an imagined building.

How does this help with Quran?

By associating verses with visual locations, you create strong spatial memories that aid recall.

What is Test Mode?

In Test Mode, you revisit rooms and try to recall which verse was placed at each glowing spot.
