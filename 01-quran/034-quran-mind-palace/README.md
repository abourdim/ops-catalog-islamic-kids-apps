# Quran Mind Palace

Memory palace technique for Quran memorization. Navigate rooms, place ayahs in locations, revisit to recall.

## Concept

Children use the method of loci (memory palace) to memorize Quran verses. They navigate virtual rooms, place verses at specific locations, then revisit rooms to test recall.

## Features

- Single HTML file, zero dependencies, fully offline
- Interactive room navigation with canvas visualization
- Place and recall ayahs in room locations
- Visual memory palace with multiple rooms
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
