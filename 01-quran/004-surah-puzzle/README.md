# Surah Puzzle

**Reconstruct the surahs of the Quran** — a jigsaw-style ordering game for Muslim kids.

## How It Works

Ayahs of a short surah are displayed **scrambled**. The child taps/clicks them in the correct order to reconstruct the surah. Correct picks move to the answer area; wrong picks flash red. After completing a surah, the app shows the surah name, English translation, and a brief tafsir note.

## Surahs Included (15)

| Difficulty | Surahs |
|---|---|
| **Easy** (3–4 ayahs) | Al-Kawthar, Al-Asr, An-Nasr, Al-Ikhlas, Quraysh |
| **Medium** (5–6 ayahs) | Al-Falaq, Al-Fil, Al-Masad, An-Nas, Al-Kafirun |
| **Hard** (7+ ayahs) | Al-Fatiha, Al-Maun, At-Takathur, Al-Qariah, Al-Zalzalah |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL auto-switch)
- Web Audio API sound effects (no files needed)
- Splash screen with بِسْمِ ٱللَّٰهِ ٱلرَّحْمَـٰنِ ٱلرَّحِيمِ
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Keyboard shortcuts (1–9 for card selection, Enter to proceed, Escape to close help)
- High score persistence via localStorage (`wdiy-hs-surah-puzzle`)
- Theme, language, and sound preferences persisted across sessions
- Progress bar and round tracking
- Post-surah completion screen with translation and tafsir
