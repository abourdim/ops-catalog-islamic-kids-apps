# Quran World Map

Interactive world map showing where Quran events took place. Click locations to read related ayahs.

## Concept

An interactive canvas-based map highlighting locations mentioned in the Quran. Click on cities and regions to learn about the events that occurred there and read related verses.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based interactive map with clickable locations
- Location info with related ayahs
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
