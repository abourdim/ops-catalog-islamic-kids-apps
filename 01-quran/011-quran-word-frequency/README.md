# Quran Word Frequency — Interactive Word Cloud

Interactive word cloud showing the most commonly mentioned words in the Quran with their meanings and approximate counts.

## Concept

A visual word cloud where the size of each word reflects how often it appears in the Quran. Kids can click any word to learn its meaning, approximate count, and significance. Words include Allah, Rabb, Mercy, Knowledge, Patience, and more.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Dynamic word cloud with size based on frequency
- Click-to-expand word details
- 25 important Quranic words included
- Preferences persisted via localStorage

## Lesson

Understanding which words Allah uses most frequently in the Quran reveals the core themes of His message: mercy, knowledge, faith, guidance, and truth.
