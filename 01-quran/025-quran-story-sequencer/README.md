# Quran Story Sequencer — Put Events in Correct Order

Interactive game where players arrange events from Quran stories in their correct chronological order.

## Concept

Events from a Quran story are shown in random order. Players click events in sequence (1st, 2nd, 3rd...) to arrange them chronologically, then check their answer. Correct positions are highlighted in green.

## Stories Included

1. Story of Prophet Yusuf (6 events)
2. Story of Prophet Musa and Pharaoh (6 events)
3. Story of Prophet Nuh and the Flood (6 events)
4. Story of Prophet Ibrahim (6 events)

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Click-to-order sequencing mechanic
- Visual feedback for correct/incorrect positions
- Score tracking and high scores via localStorage

## Lesson

Understanding the chronological flow of Quranic stories helps children see the bigger picture and learn the lessons embedded in each narrative.
