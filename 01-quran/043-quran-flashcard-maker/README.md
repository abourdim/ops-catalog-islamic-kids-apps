# Quran Flashcard Maker

Kids CREATE their own flashcards from Quran content. Add ayah, translation, notes. Spaced repetition review.

## Features

- Single HTML file, zero dependencies, fully offline
- Create, edit, and review custom flashcards
- Spaced repetition algorithm for review scheduling
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
