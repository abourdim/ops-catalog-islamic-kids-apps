# Quran Calligraphy Canvas

Interactive canvas drawing app where kids practice writing Arabic Quran verses in beautiful calligraphy styles with stroke guide overlays and multiple pen styles.

## Concept

Children learn Quran calligraphy by tracing and free-drawing Arabic verses on an HTML5 canvas. Guide strokes show the correct letterforms, and multiple pen styles (Naskh, Thuluth, Diwani) offer variety. Completed works can be admired and restarted.

## Features

- Single HTML file, zero dependencies, fully offline
- HTML5 Canvas drawing with touch and mouse support
- Stroke guide overlay with adjustable opacity
- Multiple pen styles: Naskh (thin), Thuluth (bold), Diwani (decorative)
- Color picker for ink colors
- Undo, clear, and eraser tools
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- localStorage persistence for preferences
- Multiple verse templates to practice

## Lesson

Learning to write Quran verses beautifully is an act of devotion. Arabic calligraphy has been a sacred art in Islamic civilization for over 1400 years.
