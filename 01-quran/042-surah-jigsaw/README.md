# Surah Jigsaw

Jigsaw puzzle pieces that form beautiful Islamic geometric art, each piece reveals info about a surah.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based jigsaw puzzle with draggable pieces
- Islamic geometric patterns as puzzle images
- 8 CSS themes, trilingual EN/FR/AR with RTL
- Bismillah splash, help sidebar, Web Audio API, localStorage
