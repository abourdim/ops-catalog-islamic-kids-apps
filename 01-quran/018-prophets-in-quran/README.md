# Prophets in Quran — All 25 Prophets Named in the Quran

Interactive catalog of all 25 prophets mentioned by name in the Quran with their stories, titles, and surah references.

## Concept

Browse cards for all 25 prophets named in the Quran. Each card shows the prophet's name (English and Arabic), their title/epithet, which surahs they appear in, and a description of their story and significance.

## All 25 Prophets

Adam, Idris, Nuh, Hud, Salih, Ibrahim, Lut, Ismail, Ishaq, Yaqub, Yusuf, Ayyub, Shu'ayb, Musa, Harun, Dhul-Kifl, Dawud, Sulayman, Ilyas, Al-Yasa, Yunus, Zakariyya, Yahya, Isa, Muhammad (peace be upon them all)

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Search by prophet name
- Expandable cards with detailed stories
- Surah references for each prophet
- Preferences persisted via localStorage

## Lesson

All prophets brought the same message: worship Allah alone. Learning about each prophet builds love, respect, and understanding of the chain of prophethood.
