# Abu Hurairah — Interactive Educational App

The life of Abu Hurairah — the greatest hadith narrator in history, who transmitted 5,374 narrations through his extraordinary memory and devotion to learning.

## Concept

Abu Hurairah (أبو هريرة) — explore 6 interactive chapters with trilingual content and key facts.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects
- Keyboard navigation (Arrow keys)
- Reading progress via localStorage

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | Late Conversion | Abu Hurairah got his nickname (Father of the Kitten) because he always carried a small cat he had found. |
| 2 | Devoted Student | Abu Hurairah chose poverty so he could spend every moment with the Prophet, learning and memorizing. |
| 3 | The Prophetic Gift | After the Prophet's special supplication, Abu Hurairah never forgot a single hadith he heard. |
| 4 | 5,374 Narrations | Abu Hurairah narrated 5,374 hadith — the largest collection from any single companion by far. |
| 5 | Memory Methods | Abu Hurairah divided his night into three parts: sleep, prayer, and hadith review — a systematic approach to knowledge preservation. |
| 6 | Legacy | Over 800 students transmitted hadith from Abu Hurairah, making him the most important link in hadith preservation. |
