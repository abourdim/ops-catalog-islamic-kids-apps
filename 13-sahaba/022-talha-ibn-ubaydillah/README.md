# Talha ibn Ubaydillah — Interactive Educational App

The biography of Talha ibn Ubaydillah — the Living Martyr who shielded the Prophet at Uhud, one of the ten promised Paradise.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | Early Conversion | Talha was bound and tortured by his own family but never renounced Islam. |
| 2 | Shield of the Prophet at Uhud | Talha took over 70 wounds at Uhud shielding the Prophet — the Prophet called him 'the living martyr.' |
| 3 | The Generous | Talha once distributed 700,000 dirhams in a single night, unable to sleep while he had excess wealth. |
| 4 | Legacy | Talha combined martial courage with extraordinary generosity — a complete model of Muslim character. |
