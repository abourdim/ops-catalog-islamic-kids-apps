# Sahaba Timeline — Interactive Educational App

A full chronological timeline of major companions and key events — from the first revelation to the expansion of the Islamic state.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | 610-613 CE: The Beginning | 610 CE marked the beginning with Khadijah as the first believer and Abu Bakr as the first adult man. |
| 2 | 614-619 CE: Persecution & Emigration | 614-619 CE saw emigrations, the boycott, and the devastating Year of Sorrow. |
| 3 | 620-624 CE: Hijrah & First Battles | 622 CE: The Hijrah marks the beginning of the Islamic calendar and the start of the Islamic state. |
| 4 | 625-632 CE: Trials & Victory | 625-632 CE saw the major battles, the conquest of Mecca, and the transition to the caliphate era. |
| 5 | 632-661 CE: The Rightly Guided Caliphs | The four Rightly Guided Caliphs (632-661 CE) shaped Islamic civilization for all time. |
