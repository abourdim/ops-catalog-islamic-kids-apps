# Young Companions — Interactive Educational App

Profiles of the young companions — Anas ibn Malik, Ibn Abbas, Ibn Umar, and Usama ibn Zayd — who grew up serving and learning from the Prophet.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | Anas ibn Malik | In 10 years of service, the Prophet never once scolded Anas or said 'why did you do this?' |
| 2 | Abdullah ibn Abbas | The Prophet's supplication made Ibn Abbas the greatest Quran commentator of the first generation. |
| 3 | Abdullah ibn Umar | Ibn Umar followed the Prophet's Sunnah so meticulously he would stop his camel in the exact same spots. |
| 4 | Usama ibn Zayd | At 18, Usama commanded an army that included Abu Bakr and Umar — showing Islam's merit-based leadership. |
