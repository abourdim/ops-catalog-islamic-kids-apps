# Companions at Badr — Interactive Educational App

The key companions who fought at the Battle of Badr — the first major battle of Islam and the most honored group among the companions.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | The 313 | The 313 companions at Badr are the most honored group, with the Prophet saying Allah forgave them absolutely. |
| 2 | The Three Champions | The three Muslim champions — Hamza, Ali, and Ubayda — set the tone by defeating the Quraysh champions in single combat. |
| 3 | Key Figures at Badr | The greatest companions were present at Badr — the cream of the Muslim community. |
| 4 | Divine Support | Allah sent angels to support the Muslims at Badr, as explicitly stated in Quran 8:9. |
