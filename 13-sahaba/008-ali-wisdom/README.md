# Ali's Wisdom — Interactive Educational App

Explore the famous sayings, judgments, and wisdom of Ali ibn Abi Talib — the Gate of Knowledge. An interactive collection of his most profound teachings.

## Concept

Ali's Wisdom (حكم علي) — explore 8 interactive chapters covering key events, lessons, and historical facts.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Keyboard navigation (Arrow keys for chapters)
- Reading progress persistence via localStorage
- Chapter progress tracker with visual dots
