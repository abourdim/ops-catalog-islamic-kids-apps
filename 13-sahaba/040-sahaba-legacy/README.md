# How Companions Shaped Civilization — Interactive Educational App

How the companions of the Prophet shaped Islamic civilization and left a lasting impact on law, governance, scholarship, and human values.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | Legal & Judicial Legacy | The companions created a legal system that influenced civilizations for over 1,400 years. |
| 2 | Governance & Administration | The companions created governance systems that became models for subsequent Islamic states. |
| 3 | Preservation of Knowledge | The companions preserved the Quran and hadith through rigorous methodology, ensuring Islamic knowledge survives. |
| 4 | Values & Human Rights | The companions demonstrated values of equality, justice, tolerance, and merit centuries ahead of their time. |
