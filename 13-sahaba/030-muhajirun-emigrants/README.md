# The Muhajirun — Interactive Educational App

Who were the Muhajirun? The emigrants who left everything — homes, wealth, families — for the sake of Allah and His Messenger.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | The Meaning of Hijrah | The Muhajirun left everything in Mecca — homes, wealth, families — arriving in Medina with only their faith. |
| 2 | Two Emigrations to Abyssinia | The first Muslim emigration was to Abyssinia, where a Christian king protected Muslim refugees. |
| 3 | The Great Hijrah to Medina | Suhayb al-Rumi gave up his entire fortune just to be allowed to emigrate to Medina. |
| 4 | The Muhajirun's Legacy | The Quran praises the Muhajirun and Ansar as the forerunners whom Allah is pleased with (9:100). |
