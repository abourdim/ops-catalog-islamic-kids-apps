# Abu Ubayda ibn al-Jarrah — Interactive Educational App

The biography of Abu Ubayda ibn al-Jarrah — the Trustee of the Ummah, humble commander who conquered Syria with grace and justice.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | The Trustee | The Prophet called Abu Ubayda 'the Trustee of this Ummah' — the most trusted person in the nation. |
| 2 | Supreme Commander in Syria | Despite being supreme commander, Abu Ubayda lived like an ordinary soldier, shocking Umar with his simplicity. |
| 3 | Conqueror with Justice | Abu Ubayda returned jizya to non-Muslim populations when the Muslim army could not guarantee their protection. |
| 4 | Death in the Plague | Abu Ubayda refused to leave the plague zone, choosing to stay and die alongside his soldiers. |
