# Where Companions Traveled — Interactive Educational App

An interactive exploration of where the companions traveled and settled — from Spain to China, spreading Islam across the known world.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | Arabia: The Starting Point | Medina remained the center of Islamic scholarship, with many companions staying as scholars and teachers. |
| 2 | Syria & Palestine | Syria became a major center, with Abu Ubayda, Khalid, Bilal, and many companions settling there. |
| 3 | Egypt & North Africa | Amr ibn al-As brought Islam to Egypt and founded Fustat, building the first mosque in Africa. |
| 4 | Persia, Iraq & Beyond | Companions carried Islam from Spain to China, covering the entire known world within a generation. |
