# The Ansar of Medina — Interactive Educational App

Who were the Ansar? The helpers of Medina who welcomed the Muslims, shared their homes and wealth, and became the foundation of the Islamic state.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation
