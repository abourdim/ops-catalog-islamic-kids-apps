# Family Connections — Interactive Educational App

How the companions were connected through family, marriage, and kinship — an interactive relationship map of the early Muslim community.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | The Prophet's Family | The Prophet was connected to Abu Bakr, Umar, Ali, Uthman, Hamza, and Abbas through family ties. |
| 2 | Abu Bakr's Family | Abu Bakr's entire family — his children, their spouses — all played crucial roles in early Islamic history. |
| 3 | Intermarriages | Intermarriages created a tight-knit community of companions united by both faith and family. |
| 4 | Second Generation | The second generation carried the companions' legacy, with family ties ensuring knowledge was preserved. |
