# Scribes of Revelation — Interactive Educational App

The companions who wrote down the Quran as it was revealed — Zayd ibn Thabit, Ubayy ibn Ka'b, and the other scribes who preserved the Word of Allah.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage progress, keyboard navigation

## Chapters

| # | Chapter | Key Fact |
|---|---------|----------|
| 1 | Zayd ibn Thabit | Zayd became the Prophet's scribe at just 13 and later led the Quran compilation project. |
| 2 | Ubayy ibn Ka'b | The Prophet said Ubayy ibn Ka'b was the best reciter of the Quran among all the companions. |
| 3 | Abdullah ibn Masud | Ibn Masud was the first person to publicly recite the Quran in Mecca, enduring a beating for it. |
| 4 | The Writing Materials | The scribes used palm stalks, stones, leather, and camel bones to write the Quran as it was revealed. |
| 5 | Legacy of Preservation | Over 40 companions served as scribes, creating the most accurately preserved text in human history. |
