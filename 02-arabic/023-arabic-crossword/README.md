# Arabic Crossword

Arabic crossword puzzle generator with Islamic vocabulary clues.

## Concept

An interactive crossword grid where kids fill in Arabic words based on clues. Words intersect at shared letters. Islamic-themed vocabulary about daily life, Quran, and worship.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage, back link ../../index.html
- Interactive grid with click-to-select cells
- Across and down clues with Islamic vocabulary
- Auto-check and reveal functions
