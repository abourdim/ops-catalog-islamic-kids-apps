# Days & Months — Arabic Learning Game

Learn the Arabic names of weekdays and Gregorian months through an interactive quiz designed for Muslim kids.

## Game Modes

| Difficulty | Content |
|---|---|
| **Easy** | 7 Arabic day names → English |
| **Medium** | Days + ordering questions ("What comes after Thursday?") |
| **Hard** | Days + all 12 Gregorian months in Arabic |

## Question Types

1. **Day identification** — Show Arabic day name (with tashkeel), pick the English equivalent
2. **Month identification** — Show Arabic month name, pick the English equivalent (Hard mode)
3. **Ordering** — "What day comes after X?" (Medium & Hard modes)

After each correct answer, an info box displays the Arabic (with tashkeel), transliteration, English name, and any Islamic significance notes.

## Islamic Notes

- **Friday (الجُمُعَة / al-Jumu'ah)** — The day of Jumu'ah prayer, the most blessed day of the week
- **Monday (الاِثْنَيْن / al-Ithnayn)** — The day the Prophet ﷺ was born and a recommended day for fasting

## Features

- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Sound effects via Web Audio API (no files)
- High score persistence via localStorage
- Keyboard shortcuts: 1–4 for answers, Enter to start, Escape to close help
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Single HTML file, zero dependencies, fully offline

## Storage Keys

- `wdiy-hs-days-months` — High score
- `wdiy-lang` — Language preference
- `wdiy-theme` — Theme preference
- `wdiy-mute` — Sound mute state
