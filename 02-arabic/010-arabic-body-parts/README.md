# Arabic Body Parts — Label Body Parts in Arabic

Interactive drag-and-drop game to learn body part names in Arabic (أعضاء الجسم).

## Concept

Children see a simple stick-figure body diagram with empty drop zones. Arabic labels appear in a shuffled bank below. The child drags each Arabic label to the correct body part. Correct placements lock in green; wrong attempts bounce back.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Touch and mouse drag-and-drop support
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Learning body parts in Arabic connects to daily Islamic practice — many of these parts are mentioned in wudu (ablution), prayer positions, and health-related hadiths.
