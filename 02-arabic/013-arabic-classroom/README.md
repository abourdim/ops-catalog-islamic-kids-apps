# Arabic Classroom — Learn Classroom Objects in Arabic

Interactive quiz to learn Arabic names for common classroom objects (أدوات الفصل).

## Concept

Children see an emoji of a classroom object with its English name and pick the correct Arabic word from four choices. Covers 12 essential school items.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

The first word revealed was Iqra (Read). Islam greatly values knowledge and learning.
