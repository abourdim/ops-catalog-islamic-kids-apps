# Word Builder — Build Arabic Words Letter by Letter

Interactive Arabic word-building game for Muslim kids. See an English/French meaning and transliteration, then tap the correct Arabic letters in the right order (right to left) to spell the word.

## Features

- **30 Islamic vocabulary words** across 3 difficulty levels
- **Three difficulties**: Easy (2-3 letters), Medium (4 letters), Hard (5+ letters)
- **Distractor letters** mixed in to challenge the player
- **RTL Arabic display** with large Noto Sans Arabic font
- **Trilingual UI**: English, French, Arabic (auto RTL)
- **8 CSS themes**: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- **Splash screen** with Bismillah, Start Mission, language/theme switchers
- **Progress bar, timer, score tracking** with high score persistence
- **Sound effects** via Web Audio API (no files needed)
- **Sidebar help** with FAQ, How-To, and Wiki tabs
- **Keyboard shortcuts**: Enter to start, 1-9 to pick letters, Escape to close help
- **Fully offline**: single HTML file, zero dependencies
- **Privacy-first**: no tracking, no analytics, all data stays in browser

## How to Play

1. Click **Start Mission** on the splash screen
2. Choose difficulty (Easy / Medium / Hard)
3. Read the meaning and transliteration shown
4. Tap Arabic letters in the correct order (right to left) to build the word
5. Wrong letters flash red — try again
6. Complete all words to finish the round
