What is Arabic Numbers?

A matching game to learn Arabic numbers! Match Eastern Arabic numerals (٠١٢٣…), Arabic number words (وَاحِد، اِثْنَان…), and Western digits (0, 1, 2…).

What are the three quiz modes?

1) Eastern Arabic numeral → pick the Western digit. 2) Arabic word → pick the correct digit. 3) Digit → pick the Arabic word.

🎯 Purpose

Learn Arabic numbers! Match Eastern Arabic numerals, Arabic number words, and Western digits through fun quizzes.

🔢 Numbers Covered

0-10 (Easy), 0-20 (Medium), 0-100 including tens (Hard). Eastern Arabic numerals: ٠١٢٣٤٥٦٧٨٩.

🎨 Themes

8 built-in themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand.

🌐 Languages

Trilingual: English, Français, العربية. Arabic auto-enables RTL layout.

🔊 Sound

Web Audio API — no files needed. Correct = rising tone, wrong = buzz, win = melody. Toggle with 🔊 button.

🔒 Privacy

Local-first. No tracking, no analytics, no external calls. All data stays in your browser.
