# Arabic Word Chain

Chain game where the next word must start with the last letter of the previous word.

## Concept

Kids build a chain of Arabic words. Each new word must begin with the last letter of the previous word. Uses Islamic vocabulary with hints. Chain length is tracked as the score.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage, back link ../../index.html
- Visual chain display with connected links
- Word validation with large vocabulary bank
- Score tracking by chain length
