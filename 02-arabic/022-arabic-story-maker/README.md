# Arabic Story Maker

Creative writing tool where kids build Arabic sentences by dragging word blocks to create simple stories.

## Concept

Children drag and drop Arabic word blocks into a sentence builder area. Words are categorized (subjects, verbs, objects, places) and color-coded. Kids construct grammatically simple sentences that form a short story.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Drag-and-drop word blocks with categories
- Story preview area with animated text
- High score persistence via localStorage
