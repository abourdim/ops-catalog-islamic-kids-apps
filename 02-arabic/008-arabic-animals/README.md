# Arabic Animals

**Learn animal names in Arabic** — an interactive vocabulary game for Muslim kids.

## How It Works

- **Emoji to Arabic**: See an animal emoji + English name, pick the correct Arabic name from 4 options.
- **Arabic to Emoji**: See the Arabic name, pick the correct animal emoji.
- **Mixed mode**: Alternates between both directions.

## Difficulty Levels

- **Easy (10)**: Common animals (lion, elephant, camel, horse, cat, dog, bird, fish, bee, butterfly)
- **Medium (18)**: Adds rooster, cow, sheep, goat, rabbit, dove, ant, spider
- **Hard (25+)**: All 28 animals

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Web Audio sound effects (no audio files)
- Keyboard shortcuts: 1-4 for answers, Enter to start, Escape to close help
- High score persistence via localStorage
- Theme/language/sound preferences persisted
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Progress bar and score tracking
- Activity log

## Storage Keys

- `wdiy-hs-arabic-animals` — High score (percentage)
- `wdiy-lang` — Language preference
- `wdiy-theme` — Theme preference
- `wdiy-mute` — Sound mute state
