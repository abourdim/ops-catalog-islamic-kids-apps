# Arabic Prepositions — Interactive Scenes Teaching Prepositions

Interactive visual game teaching Arabic prepositions with animated scenes (حروف الجر).

## Concept

Children see a visual scene with a cat and a reference object. They must pick the correct Arabic preposition describing the spatial relationship. Covers 12 essential prepositions.

## The 12 Prepositions

| # | Arabic | English | French |
|---|--------|---------|--------|
| 1 | فَوْقَ | Above | Au-dessus |
| 2 | تَحْتَ | Under | Sous |
| 3 | بِجَانِبِ | Beside | À côté |
| 4 | أَمَامَ | In front of | Devant |
| 5 | وَرَاءَ | Behind | Derrière |
| 6 | فِي | In / Inside | Dans |
| 7 | عَلَى | On | Sur |
| 8 | بَيْنَ | Between | Entre |
| 9 | قَرِيبٌ مِنْ | Near | Près de |
| 10 | بَعِيدٌ عَنْ | Far from | Loin de |
| 11 | حَوْلَ | Around | Autour de |
| 12 | إِلَى | Towards | Vers |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Visual emoji scenes for each preposition
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

Prepositions are essential for forming sentences in Arabic. Many Quranic phrases use these prepositions in prayers and descriptions.
