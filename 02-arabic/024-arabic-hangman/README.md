# Arabic Hangman

Classic hangman game with Arabic Islamic vocabulary words.

## Concept

Kids guess Arabic letters to reveal hidden Islamic vocabulary words. A crescent moon drawing gradually appears with each wrong guess. Correct words teach Islamic terms.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage, back link ../../index.html
- Canvas-based crescent moon drawing (replaces traditional hangman)
- 40+ Islamic vocabulary words with meanings
- Animated letter reveal
