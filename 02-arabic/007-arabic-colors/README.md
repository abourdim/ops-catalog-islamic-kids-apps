# Arabic Colors

Learn colors in Arabic with full tashkeel (vowel marks).

## Game

Two quiz modes mixed randomly:

1. **Color to Name** — A large colored circle is shown; pick the correct Arabic color name from 4 options.
2. **Name to Color** — An Arabic color word is shown; pick the matching colored square from 4 options.

After each correct answer, the Arabic name, transliteration, and English name are displayed together.

## Difficulty

- **Easy** — 8 basic colors (Red, Blue, Yellow, Green, White, Black, Orange, Purple)
- **Medium** — 12 colors (adds Pink, Brown, Gray, Gold)
- **Hard** — All 15 colors

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Web Audio sound effects (toggle on/off)
- Keyboard shortcuts: 1-4 for answers, Enter to start, Escape to close help
- High score persistence via localStorage
- Theme, language, and sound preferences persisted
- Sidebar help with FAQ, How-To, and Wiki tabs
