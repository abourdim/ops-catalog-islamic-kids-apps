# Arabic Verbs — Learn Arabic Verb Conjugations

Interactive quiz to learn basic Arabic verb conjugations in past tense (الأفعال العربية).

## Concept

Children see an Arabic verb root with its meaning and a pronoun, then must pick the correctly conjugated form from four choices. Covers 6 common verbs across multiple pronouns.

## Verbs Covered

- كَتَبَ (kataba) — wrote
- ذَهَبَ (dhahaba) — went
- أَكَلَ (akala) — ate
- قَرَأَ (qara'a) — read
- جَلَسَ (jalasa) — sat
- شَرِبَ (shariba) — drank

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

Arabic verbs follow a beautiful root-pattern system. Understanding conjugation is key to reading the Quran and speaking Arabic fluently.
