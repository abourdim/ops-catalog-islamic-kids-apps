# Arabic Typing Tutor

Arabic keyboard typing practice with on-screen keyboard and timed exercises.

## Concept

Children practice typing Arabic letters using an on-screen virtual keyboard. Words appear and kids type them. Tracks WPM, accuracy, and provides visual feedback on key presses.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage, back link ../../index.html
- Visual on-screen Arabic keyboard with key highlighting
- WPM and accuracy tracking
- Progressive difficulty with Islamic vocabulary
