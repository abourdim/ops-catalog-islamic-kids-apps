# Arabic Diacritics Trainer

Add correct harakat (fatha, damma, kasra, shadda, sukun) to bare Arabic words.

## Concept

Arabic words are shown without diacritics. Kids tap on each letter to cycle through and add the correct harakat. Teaches proper vowelization essential for Quran reading.
