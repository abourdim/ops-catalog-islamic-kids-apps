# Arabic Root Explorer

Interactive root system explorer. Enter a 3-letter root and see all derived words branch out like a tree.

## Concept

Kids explore the Arabic root system by selecting a 3-letter root. The app displays derived words as an animated tree/branch visualization, showing how one root generates many related words.
