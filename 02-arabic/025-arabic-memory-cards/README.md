# Arabic Memory Cards

Flip card memory game matching Arabic words to their meanings.

## Concept

Classic memory/concentration game with Islamic vocabulary. Cards are placed face-down. Flip two cards to find matching pairs (Arabic word + its meaning). Features animated card flips.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage, back link ../../index.html
- CSS 3D card flip animations
- Multiple difficulty levels (4, 8, 12 pairs)
- Move counter and timer
