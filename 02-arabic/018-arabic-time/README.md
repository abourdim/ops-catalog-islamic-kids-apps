# Arabic Time — Learn to Tell Time in Arabic

Interactive clock game to learn telling time in Arabic (الساعة بالعربية).

## Concept

Children see an interactive analog clock displaying a time and must pick the correct Arabic time phrase from four choices. Covers all 12 hours plus half-hour variations.

## Features

- Single HTML file, zero dependencies, fully offline
- Interactive CSS analog clock with hour and minute hands
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

The five daily prayers are tied to specific times, teaching Muslims to be mindful of time. Learning to tell time in Arabic connects language to daily worship.
