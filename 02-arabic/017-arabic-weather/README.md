# Arabic Weather — Learn Weather Words in Arabic

Interactive quiz to learn Arabic weather vocabulary with animated emojis (أحوال الطقس).

## Concept

Children see an animated weather emoji and must pick the correct Arabic name. Covers 10 weather types with floating animations.

## The 10 Weather Types

| # | Emoji | Arabic | English | French |
|---|-------|--------|---------|--------|
| 1 | ☀️ | شَمْس | Sun | Soleil |
| 2 | 🌧️ | مَطَر | Rain | Pluie |
| 3 | ❄️ | ثَلْج | Snow | Neige |
| 4 | 💨 | رِيَاح | Wind | Vent |
| 5 | ☁️ | غُيُوم | Clouds | Nuages |
| 6 | ⛈️ | عَاصِفَة | Storm | Tempête |
| 7 | 🌈 | قَوْس قُزَح | Rainbow | Arc-en-ciel |
| 8 | 🌡️ | حَرَارَة | Heat | Chaleur |
| 9 | 🌫️ | ضَبَاب | Fog | Brouillard |
| 10 | ⚡ | بَرْق | Lightning | Éclair |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Animated floating weather icons
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

Muslims make dua during rain. The Prophet ﷺ taught specific prayers for various weather conditions.
