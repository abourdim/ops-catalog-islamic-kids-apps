# Arabic Shapes — Identify Geometric Shapes in Arabic

Interactive visual quiz to learn Arabic names for geometric shapes (الأشكال الهندسية).

## Concept

Children see an SVG-drawn geometric shape and must pick the correct Arabic name from four choices. Covers 10 shapes with clean vector graphics.

## The 10 Shapes

| # | Arabic | English | French |
|---|--------|---------|--------|
| 1 | دَائِرَة | Circle | Cercle |
| 2 | مُرَبَّع | Square | Carré |
| 3 | مُثَلَّث | Triangle | Triangle |
| 4 | مُسْتَطِيل | Rectangle | Rectangle |
| 5 | نَجْمَة | Star | Étoile |
| 6 | مُعَيَّن | Diamond | Losange |
| 7 | بَيْضَاوِي | Oval | Ovale |
| 8 | خُمَاسِي | Pentagon | Pentagone |
| 9 | سُدَاسِي | Hexagon | Hexagone |
| 10 | قَلْب | Heart | Coeur |

## Features

- Single HTML file, zero dependencies, fully offline
- SVG-drawn shapes (no images needed)
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

Islamic art is world-famous for its geometric patterns. Muslim mathematicians advanced geometry significantly.
