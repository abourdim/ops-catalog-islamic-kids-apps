# Arabic Handwriting Practice

Canvas-based Arabic letter handwriting practice app. Kids draw letters on a canvas and get visual stroke accuracy feedback.

## Concept

Children select an Arabic letter, see a guide overlay, then draw it on a touch/mouse canvas. The app evaluates stroke accuracy by comparing drawn pixels against the reference pattern and gives a score with visual feedback.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Canvas-based drawing with touch and mouse support
- Reference letter overlay with opacity control
- Stroke accuracy scoring
- All 28 Arabic letters
- High score persistence via localStorage

## Lesson

Learning to write Arabic letters correctly is the foundation of reading the Quran and understanding the Arabic language.
