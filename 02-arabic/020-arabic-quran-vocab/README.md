# Quranic Arabic Vocab — Learn Common Quranic Vocabulary

Interactive quiz to learn the most common Arabic words found in the Quran (مفردات القرآن).

## Concept

Children see a Quranic Arabic word with its surah reference and frequency, then pick the correct meaning from four choices. Covers 12 essential Quranic words.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Shows surah reference and word frequency
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

Understanding Quranic vocabulary transforms the prayer experience. About 80% of the Quran can be understood by learning a few hundred key words.
