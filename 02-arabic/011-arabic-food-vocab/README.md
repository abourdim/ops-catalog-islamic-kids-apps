# Arabic Food Vocab — Learn Arabic Food Vocabulary

Interactive quiz game to learn Arabic food vocabulary with emoji cards (مفردات الطعام).

## Concept

Children see a food emoji and must pick the correct Arabic word from four options. The game covers 12 common foods, many mentioned in the Quran and Hadith.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Many of these foods are mentioned in the Quran — dates, olives, grapes, honey, and milk. The Prophet ﷺ taught us to say Bismillah before eating.
