# Arabic Opposites — Match Arabic Antonyms

Interactive game to match Arabic words with their opposites (الأضداد).

## Concept

Children see an Arabic word and must pick its opposite from four choices. Covers 12 antonym pairs with diacritics for proper pronunciation.

## The 12 Opposite Pairs

| # | Word | Opposite | English | French |
|---|------|----------|---------|--------|
| 1 | كَبِير | صَغِير | Big / Small | Grand / Petit |
| 2 | حَارّ | بَارِد | Hot / Cold | Chaud / Froid |
| 3 | طَوِيل | قَصِير | Tall / Short | Grand / Court |
| 4 | سَرِيع | بَطِيء | Fast / Slow | Rapide / Lent |
| 5 | جَدِيد | قَدِيم | New / Old | Nouveau / Ancien |
| 6 | سَهْل | صَعْب | Easy / Hard | Facile / Difficile |
| 7 | قَرِيب | بَعِيد | Near / Far | Proche / Loin |
| 8 | فَوْق | تَحْت | Above / Below | Au-dessus / En-dessous |
| 9 | يَمِين | يَسَار | Right / Left | Droite / Gauche |
| 10 | نَهَار | لَيْل | Day / Night | Jour / Nuit |
| 11 | أَبْيَض | أَسْوَد | White / Black | Blanc / Noir |
| 12 | ثَقِيل | خَفِيف | Heavy / Light | Lourd / Léger |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR with RTL), Bismillah splash
- Sidebar help with FAQ, How-To, Wiki tabs
- Web Audio API sounds, localStorage high scores

## Lesson

Learning antonyms doubles vocabulary efficiency. Many of these pairs appear in the Quran and daily conversation.
