# Arabic Sentence Scramble

Unscramble jumbled Arabic sentences into correct grammar order.

## Concept

Arabic sentences are presented with words in random order. Kids drag/tap words to rearrange them into grammatically correct sentences. Teaches Arabic sentence structure (VSO and nominal).

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual EN/FR/AR with RTL, Bismillah splash, help sidebar
- Web Audio API sounds, localStorage, back link ../../index.html
