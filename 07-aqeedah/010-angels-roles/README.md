# Angels Roles

Match angels to their roles and duties.

## Concept

Quiz: match Jibril (revelation), Mikail (provision), Israfil (trumpet), Angel of Death (souls), and Raqib/Atid (recording deeds) to their roles.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz matching 5 angels to their duties
- High score persistence via localStorage

## Lesson

Angels are noble servants of Allah created from light. Knowing their roles increases our awareness of the unseen world.
