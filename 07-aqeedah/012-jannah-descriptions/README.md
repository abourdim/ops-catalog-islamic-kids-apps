# Jannah Descriptions

Explore Quranic descriptions of Paradise interactively.

## Concept

Step through descriptions: rivers of Paradise, freedom from pain, palaces and gardens, seeing Allah, and what no eye has seen.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 5 Quranic descriptions explored
- High score persistence via localStorage

## Lesson

Jannah motivates the believer to do good. Its descriptions in the Quran and Sunnah give us hope and inspiration to strive for excellence.
