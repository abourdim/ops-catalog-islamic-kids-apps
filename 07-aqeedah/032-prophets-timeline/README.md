# Prophets Timeline

Full timeline of all 25 prophets with interactive entries and key events.

## Concept

An interactive chronological timeline of all 25 prophets mentioned in the Quran, from Adam to Muhammad, with key events and details for each.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

All prophets brought the same message of Tawheed. Seeing them in timeline form shows the continuity of Allah's guidance throughout human history.
