# Jannah vs Jahannam

Side-by-side comparison of Quran descriptions of Jannah vs Jahannam.

## Concept

A side-by-side visual comparison of Quranic descriptions of Paradise (Jannah) and Hellfire (Jahannam), helping children understand the consequences of faith and action.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Understanding the reality of Jannah and Jahannam motivates us to strive for good and avoid evil. Both are real destinations awaiting us.
