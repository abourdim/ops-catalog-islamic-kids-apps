# Tawheed Categories

Learn about the three categories of Tawheed.

## Concept

Explore Tawheed ar-Rububiyyah (Lordship), Tawheed al-Uluhiyyah (Worship), and Tawheed al-Asma wa Sifat (Names and Attributes).

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 3 categories of Tawheed explained
- High score persistence via localStorage

## Lesson

Tawheed is the foundation of Islam. Understanding its categories protects the Muslim from deviation and strengthens pure worship of Allah alone.
