# Qadr Balance

Balance scale showing how to accept divine decree. Interactive scenarios.

## Concept

An interactive balance scale with scenarios about accepting divine decree (Qadr). Children respond to life situations and learn the Islamic perspective.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Belief in Qadr (divine decree) means trusting Allah's plan. This teaches children patience in hardship and gratitude in blessings — both are from Allah.
