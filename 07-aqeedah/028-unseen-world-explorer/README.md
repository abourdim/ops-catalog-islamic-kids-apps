# Unseen World Explorer

Explore the world of the unseen (ghayb) through Quran references.

## Concept

An interactive catalog of unseen realities mentioned in the Quran: angels, jinn, the soul, Paradise, Hellfire, the Throne, and more. Each entry includes Quran references.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Belief in the unseen (ghayb) is the first quality of the believers mentioned in Surah Al-Baqarah. Exploring what Allah has revealed about the unseen strengthens faith.
