# Promise of Allah

Collection of Allah's promises in the Quran. Click to explore context and meaning.

## Concept

An interactive collection of Allah's promises from the Quran. Each promise card shows the Arabic text, translation, and context of the promise.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Allah never breaks His promises. Reflecting on them builds trust (tawakkul) in Allah and gives hope during difficult times.
