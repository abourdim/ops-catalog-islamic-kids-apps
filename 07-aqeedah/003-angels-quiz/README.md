# Angels of Islam — Quiz Game

> Learn about Allah's angels — their names, duties, and references in Quran & Hadith.

## Overview

An interactive quiz game for Muslim kids. A duty or description of an angel is shown and the player picks the correct angel name from 4 choices. After a correct answer, the Arabic name, role, and Quran/Hadith reference are displayed.

**Belief in angels is the second pillar of Iman.**

## Difficulty Levels

- **Easy** — 4 main angels (Jibril, Mikail, Israfil, Malak al-Mawt), 8 questions
- **Medium** — 8 angels (adds Munkar & Nakir, Raqib & Atid, Malik, Ridwan), 12 questions
- **Hard** — All 10+ angels including Kiraman Katibin and Hamalat al-Arsh, 15 questions

## Question Types

- Duties and roles of each angel
- Quran verse references
- Which angel appeared to which prophet
- Special characteristics (e.g., 600 wings, trumpet blasts)
- Pillar of Iman connection

## Features

- 20+ questions across all difficulty levels
- Arabic name, role, and source displayed after correct answers
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Sound effects via Web Audio API (no files)
- Keyboard shortcuts: 1-4 for answers, Enter to start, Escape to close help
- High score persistence (localStorage)
- Theme, language, and sound preferences persisted
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Progress bar and score tracking
- Single HTML file, zero dependencies, fully offline

## Tech

- Single-file HTML (`index.html`)
- Zero external dependencies (fonts loaded from Google Fonts, optional)
- localStorage key: `wdiy-hs-angels-quiz`
- Works on any modern browser — phone, tablet, desktop
