# Pillars Builder

**Build the foundations of Islam and Iman**

An interactive visual pillar-building game for Muslim kids. Players place the Pillars of Islam and Pillars of Iman in the correct order on a canvas structure, learning Arabic terms, meanings, and Quran verse references along the way.

## Gameplay

- A building foundation is drawn on canvas with empty pillar slots
- Shuffled cards appear below — tap/click the correct next pillar
- Each correct placement raises a pillar column with animation
- An info box shows the Arabic term, English meaning, explanation, and Quran verse
- Once all pillars are placed, a roof is added and a celebration animation plays
- Mistakes are tracked but do not block progress

## Difficulty Levels

| Level  | Content                        | Pillars |
|--------|--------------------------------|---------|
| Easy   | 5 Pillars of Islam             | 5       |
| Medium | 6 Pillars of Iman              | 6       |
| Hard   | All Pillars (Islam + Iman)     | 11      |

## Pillars of Islam

1. **Shahada** — Declaration of Faith
2. **Salah** — Prayer
3. **Zakat** — Almsgiving
4. **Sawm** — Fasting
5. **Hajj** — Pilgrimage

## Pillars of Iman

1. **Belief in Allah**
2. **Belief in Angels**
3. **Belief in Holy Books**
4. **Belief in Prophets**
5. **Belief in the Day of Judgment**
6. **Belief in Qadar** (Divine Decree)

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based visual building with pillar animations
- Celebratory particle animation on completion
- Arabic terms with English meanings and Quran references
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Sound effects via Web Audio API (no audio files)
- High score persistence via localStorage
- Keyboard shortcuts (1-9 for cards, Enter to start, Esc to close help)
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Responsive design for phone, tablet, and desktop

## Storage Keys

- `wdiy-hs-pillars-builder` — High score
- `wdiy-lang` — Language preference
- `wdiy-theme` — Theme preference
- `wdiy-mute` — Sound mute state

## Usage

Open `index.html` in any modern browser. No server required.
