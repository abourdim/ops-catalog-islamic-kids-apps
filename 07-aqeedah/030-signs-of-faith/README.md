# Signs of Faith

Interactive checklist of signs of strong iman. Self-assessment tool.

## Concept

A self-assessment checklist based on hadith describing the signs and characteristics of strong iman. Children check which qualities they practice.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Self-assessment is important in Islam. Umar (may Allah be pleased with him) said: Take account of yourselves before you are taken to account.
