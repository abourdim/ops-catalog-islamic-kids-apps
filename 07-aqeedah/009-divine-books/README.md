# Divine Books

Learn about the 4 divine books revealed by Allah.

## Concept

Step through the Tawrat (Torah), Zabur (Psalms), Injil (Gospel), and Quran — learning which prophet received each and its purpose.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 4-step exploration of divine books
- High score persistence via localStorage

## Lesson

Allah sent books of guidance throughout history. The Quran is the final, preserved revelation that confirms and completes all previous scriptures.
