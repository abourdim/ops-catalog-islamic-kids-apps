# Qadr Scenarios

Understand divine decree through everyday scenarios.

## Concept

Everyday situations: missing the bus, getting a good grade, rain on a picnic, losing a toy. Choose the correct Islamic response.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 4 everyday scenario questions
- High score persistence via localStorage

## Lesson

Believing in Qadr means trusting Allah's plan in all circumstances. It brings peace in hardship and humility in success.
