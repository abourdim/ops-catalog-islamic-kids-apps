# Day of Judgment — Interactive Learning Game

An interactive, kid-friendly game teaching the events of Yawm al-Qiyamah (the Day of Judgment) in chronological order, with quiz questions about Akhirah concepts.

## Features

- **Order Mode**: Drag-and-drop (or click) shuffled event cards into the correct chronological sequence
- **Quiz Mode**: Multiple-choice questions about Akhirah concepts (Sirat, Mizan, Hawd, Shafa'ah, etc.)
- **3 Difficulty Levels**: Easy (7 events), Medium (11 events), Hard (all 15 events + quiz)
- **Quran/Hadith References**: After each correct answer, a reference and kid-friendly explanation is shown
- **Kid-Friendly Tone**: Emphasizes Allah's mercy and hope throughout
- **8 CSS Themes**: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- **3 Languages**: English, French, Arabic (RTL auto-enabled)
- **Sound Effects**: Web Audio API — correct, wrong, and win sounds (toggle on/off)
- **High Score**: Persisted in localStorage
- **Keyboard Shortcuts**: 1-4 for quiz answers, Enter to start, C to check order, Escape to close help
- **Sidebar Help**: FAQ, How-To, and Wiki tabs
- **Offline**: Single HTML file, zero dependencies

## Events Covered (15 total)

1. Trumpet blown by Israfil (first blow — everything dies)
2. Second trumpet blow (resurrection)
3. People rise from their graves
4. Gathering at the plain of Hashr
5. Sun brought very close to people
6. People seek intercession from prophets
7. Prophet Muhammad ﷺ intercedes (Shafa'ah)
8. Books of deeds given (right hand = success)
9. Deeds weighed on the Mizan (Scale)
10. The Hawd (Pool of the Prophet ﷺ)
11. Crossing the Sirat (bridge over Hell)
12. Those who fall enter Jahannam
13. Believers enter Jannah
14. Seeing Allah in Jannah
15. Eternal life begins

## Quiz Topics

- What is Shafa'ah?
- What is the greatest reward in Jannah?
- And more...

## Usage

Open `index.html` in any modern browser. No server or build step required.

## Storage Keys

- `wdiy-hs-day-judgment` — High score (percentage)
- `wdiy-lang` — Language preference
- `wdiy-theme` — Theme preference
- `wdiy-mute` — Sound mute state
