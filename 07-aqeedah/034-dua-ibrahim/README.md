# Duas of Ibrahim

Explore Prophet Ibrahim's famous duas from the Quran. Interactive with context.

## Concept

An interactive explorer of Prophet Ibrahim's most famous duas from the Quran, each with Arabic text, translation, context, and lesson.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Ibrahim (peace be upon him) is called the friend of Allah. His duas teach us how to ask Allah with sincerity, humility, and beautiful words.
