# Prophets Chain

Build the chain of prophets from Adam to Muhammad.

## Concept

Step through key prophets: Adam, Nuh, Ibrahim, Musa, Isa, and Muhammad (peace be upon them all), learning their stories and missions.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 6 key prophets with descriptions
- High score persistence via localStorage

## Lesson

Allah sent prophets throughout history with one message: worship Allah alone. Muhammad is the final messenger, completing the chain.
