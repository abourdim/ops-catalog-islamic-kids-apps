# Names of Allah Calligraphy

Canvas calligraphy practice for the 99 Names of Allah. Trace and draw.

## Concept

A canvas calligraphy tool where children practice writing the 99 Names of Allah in Arabic script. Each name is displayed as a guide to trace over.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The 99 Names of Allah teach us about His attributes. Writing them in calligraphy combines art with dhikr (remembrance of Allah).
