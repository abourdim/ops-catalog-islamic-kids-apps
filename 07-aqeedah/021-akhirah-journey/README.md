# Akhirah Journey

Interactive visualization of the journey after death. Stages of the afterlife.

## Concept

An interactive journey through the stages of the afterlife as described in the Quran and Sunnah. Children explore each stage from death to Paradise.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Belief in the Akhirah (afterlife) is a pillar of iman. Understanding the journey motivates us to prepare through good deeds in this life.
