# Pillars Puzzle

Build the 5 pillars and 6 pillars of iman as interlocking structures.

## Concept

A puzzle where children build the five pillars of Islam and six pillars of iman by placing blocks in the correct order on a foundation structure.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The pillars of Islam and iman are the foundation of every Muslim's life. Knowing them by heart and understanding their order is essential.
