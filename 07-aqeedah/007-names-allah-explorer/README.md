# Names of Allah Explorer

Deep dive into the 99 Names of Allah with meanings.

## Concept

Quiz format: see a Name of Allah and choose its correct meaning. Learn Ar-Rahman, Al-Malik, Al-Alim, Al-Ghaffar, As-Samad, Al-Wadud and more.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Quiz on Names and their meanings
- High score persistence via localStorage

## Lesson

Knowing Allah's Names deepens love and awareness of Him. Each Name reveals an aspect of His perfection.
