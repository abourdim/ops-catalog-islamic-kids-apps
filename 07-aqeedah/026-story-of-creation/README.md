# Story of Creation

Interactive timeline of creation. From the Throne to Earth. Visual journey.

## Concept

An interactive visual timeline of creation as described in the Quran and Sunnah, from the Throne of Allah to the creation of Adam and his placement on Earth.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Understanding the story of creation deepens our awe of Allah's power and wisdom. Everything was created with purpose and precision.
