# Prophet Stories Map

World map showing where each prophet's story took place. Click to explore.

## Concept

An interactive world map with markers for each prophet's location. Click on a marker to learn about the prophet, their people, and their message.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

The prophets were sent to all nations. Seeing their stories on a map shows the global scope of Allah's guidance throughout history.
