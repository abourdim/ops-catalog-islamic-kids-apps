# Names of Allah Memory

Advanced memory game with 99 Names pairs (Arabic + meaning).

## Concept

A memory card game where children match Arabic names of Allah with their English meanings. Cards flip over and must be matched from memory.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Memorizing Allah's names is highly rewarded. The Prophet said whoever memorizes 99 names enters Paradise. This game makes learning them fun.
