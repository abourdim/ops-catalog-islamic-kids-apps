❓ Help
How do I play?

Click two cards to flip them. If they match (Arabic name + meaning), they stay flipped.

How many pairs?

8 pairs per game (16 cards). Cards are shuffled each time.

Do I learn all 99 names?

A subset is shown each game. Play multiple times to learn more names!
