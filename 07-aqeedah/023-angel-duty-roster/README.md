# Angel Duty Roster

Assign angels to their duties. Learn angel responsibilities in a scheduling game.

## Concept

A matching game where children assign famous angels to their duties as described in the Quran and Sunnah. Drag each angel to the correct role.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Angels are created from light and obey Allah completely. Learning about them strengthens our belief in the unseen, a pillar of faith.
