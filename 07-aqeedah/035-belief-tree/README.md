# Belief Tree

Growing tree: roots = aqeedah, trunk = pillars, branches = actions, fruits = rewards.

## Concept

A growing tree visualization where roots represent aqeedah foundations, the trunk represents pillars of Islam, branches represent good actions, and fruits represent rewards.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Faith is like a tree — it needs strong roots (beliefs), a solid trunk (pillars), healthy branches (actions), and bears beautiful fruits (rewards from Allah).
