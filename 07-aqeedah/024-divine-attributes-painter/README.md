# Divine Attributes Painter

Paint inspired by divine attributes. Ar-Rahman = warm colors. Creative art tool.

## Concept

A creative painting tool where each divine attribute suggests a color palette and mood. Ar-Rahman inspires warm colors, Al-Jaleel inspires grand strokes, etc.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Allah's attributes inspire endless reflection. Connecting art with divine names helps children experience the beauty and depth of each attribute.
