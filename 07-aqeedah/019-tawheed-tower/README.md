# Tawheed Tower

Build a tower of faith. Each block is a concept of Tawheed. Stack correctly.

## Concept

A tower-building game where each block represents a concept of Tawheed (Islamic monotheism). Children must stack them in the correct theological order.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Tawheed is the foundation of Islam — the belief in the absolute Oneness of Allah. Building it block by block teaches the structure of Islamic belief.
