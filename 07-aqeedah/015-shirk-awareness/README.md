# Shirk Awareness

Identify and avoid different forms of shirk — educational scenarios.

## Concept

Scenario quiz: asking the dead for help, wearing lucky charms, showing off in prayer, swearing by other than Allah. Learn what constitutes shirk.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 4 educational scenarios on shirk
- High score persistence via localStorage

## Lesson

Shirk is the greatest sin in Islam. This educational tool helps children identify and avoid it, strengthening their Tawheed.
