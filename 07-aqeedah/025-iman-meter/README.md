# Iman Meter

Daily iman tracker. Log good deeds, dhikr, Quran reading. Visualize faith growth.

## Concept

A daily tracker where children log their good deeds, prayers, Quran reading, and dhikr. The iman meter rises with each entry, showing faith growth visually.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Iman increases with obedience and decreases with disobedience. Tracking our deeds daily helps maintain and grow our connection with Allah.
