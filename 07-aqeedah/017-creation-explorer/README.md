# Creation Explorer

Explore Allah's creation from atoms to galaxies. Zoom in/out visualization.

## Concept

A zoom-based explorer showing the scale of Allah's creation from subatomic particles to the entire universe. Children zoom in and out to discover different levels.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage

## Lesson

Reflecting on creation (tafakkur) is an act of worship. From the smallest atom to the largest galaxy, everything proclaims the glory of its Creator.
