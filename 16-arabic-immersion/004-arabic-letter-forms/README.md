# Arabic Letter Forms

Interactive display of all 28 Arabic letters in their 4 positional forms (isolated, initial, medial, final) with example words.

## Features

- All 28 Arabic letters
- 4 forms per letter displayed
- Example words for each letter
- Click-to-select interface
- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects
- Progress saved via localStorage

## Lesson

Recognizing Arabic letters in all positions is essential for reading fluency. Each form looks different but represents the same sound.
