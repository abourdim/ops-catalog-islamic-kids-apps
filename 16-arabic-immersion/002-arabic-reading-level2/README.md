# Arabic Reading Level 2 — Short Paragraphs

Interactive Arabic reading comprehension with short Islamic story paragraphs, vocabulary building, and comprehension questions.

## Concept

Short Arabic paragraphs from Islamic stories (Prophet's mercy, Ramadan, Five Pillars, etc.). Each paragraph has tap-to-learn vocabulary, full translation toggle, and a comprehension question.

## Features

- 10 short Arabic paragraphs with Islamic themes
- Tap words for vocabulary lookup
- Full translation toggle
- Comprehension questions with instant feedback
- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects
- Progress saved via localStorage

## Lesson

Reading short paragraphs in Arabic builds comprehension skills beyond individual words. Islamic story contexts make learning meaningful and connected to faith.
