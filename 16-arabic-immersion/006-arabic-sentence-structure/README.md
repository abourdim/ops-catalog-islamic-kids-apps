# Arabic Sentence Structure

Interactive visual Arabic sentence diagramming with color-coded grammatical roles.

## Features

- 7 Arabic sentences\n- Color-coded roles (verb, subject, object, preposition)\n- Verbal and nominal sentence types
- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sound effects, localStorage progress

## Lesson

Understanding sentence structure is key to reading Arabic fluently.
