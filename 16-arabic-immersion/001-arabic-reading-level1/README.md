# Arabic Reading Level 1 — Simple Sentences

Interactive word-by-word Arabic reading tool for beginners. Tap any word in simple Arabic sentences to see its meaning, transliteration, and grammar notes.

## Concept

Simple Arabic sentences from Islamic contexts (mosque, family, nature, daily life). Each sentence is displayed in large Arabic text. Tapping any word reveals its English/French translation, transliteration, and grammatical role.

## Features

- 20 simple Arabic sentences with word-by-word breakdown
- Tap any word to see meaning, transliteration, and grammar
- Full sentence translation toggle
- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Progress saved via localStorage
- Keyboard navigation (arrow keys)

## Lesson

Reading Arabic word-by-word builds vocabulary and comprehension. Understanding individual words helps children move from memorized recitation to true understanding of Arabic texts.
