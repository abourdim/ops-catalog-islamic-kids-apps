# Arabic Reading Level 3

Interactive guided reading of full Arabic passages from Quran and Hadith with tap-to-learn vocabulary and translation support.

## Features

- 5 full Arabic passages from Quran and Hadith
- Tap any word for meaning and grammar
- Full translation toggle
- Source citations for each passage
- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects
- Progress saved via localStorage

## Lesson

Reading authentic Islamic texts in Arabic connects language learning directly to faith. Understanding Quran and Hadith word-by-word deepens both knowledge and iman.
