# Arabic Text Analyzer

Arabic text analyzer with word-by-word breakdown.

## Features

- Paste any Arabic text\n- Word count and stats\n- Basic grammar detection
- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sound effects, localStorage progress

## Lesson

Analyzing Arabic text builds reading comprehension skills.
