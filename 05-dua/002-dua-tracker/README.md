# Dua Practice

**Learn and practice daily supplications**

An interactive dua practice tracker for Muslim kids. Browse, learn, and quiz yourself on 28 daily duas organized by time of day.

## Features

- **Learn Mode**: Browse duas as flashcards — tap to flip between Arabic text and English translation/transliteration. Navigate with arrows or swipe.
- **Quiz Mode**: Given an occasion (e.g. "Before eating"), pick the correct Arabic dua from 4 options.
- **28 Duas** organized by time: Morning (6), Afternoon (6), Evening (4), Night (4), Anytime (8)
- **3 Difficulty Levels**: Easy (10 common), Medium (15), Hard (25+)
- **Full Arabic text** with tashkeel, transliteration, and English meaning
- **8 CSS Themes**: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- **Trilingual UI**: English, French, Arabic (with RTL support)
- **Sound effects** via Web Audio API (no external files)
- **High score** persistence via localStorage
- **Keyboard shortcuts**: 1-4 for quiz answers, arrows for navigation, Space to flip, L/Q to switch modes, Enter to start
- **Touch swipe** support for mobile
- **Single HTML file**, zero dependencies, fully offline

## Dua Categories

| Time | Duas |
|------|------|
| Morning | Waking up, Looking in mirror, Leaving home, Entering vehicle, Entering school, Morning remembrance |
| Afternoon | Before eating, After eating, Before drinking, After drinking, Entering bathroom, Leaving bathroom |
| Evening | Entering home, Changing clothes, Before studying, After studying |
| Night | Before sleeping, Night prayer, Seeking protection, Last before sleep, Evening remembrance |
| Anytime | When it rains, Hearing thunder, Seeing new moon, Sneezing, For parents, Entering mosque, Leaving mosque |

## Usage

Open `index.html` in any modern browser. No server or build step required.
