# Islamic Inventions Match

An interactive matching game for Muslim kids to discover the incredible contributions of Muslim scholars to science, medicine, mathematics, astronomy, and more.

## Game

A discovery or invention is shown on screen. The player picks the correct Muslim scholar/inventor from 4 choices. After a correct answer, an info card displays the scholar's name (Arabic + English), era, and how the invention changed the world.

## Difficulty Levels

| Level  | Questions | Content                              |
|--------|-----------|--------------------------------------|
| Easy   | 10        | Famous inventions (algebra, optics, surgery, etc.) |
| Medium | 15        | Adds coffee, hospitals, chemistry, sociology, etc. |
| Hard   | 25+       | Full set including cryptanalysis, automatons, windmills, inoculation |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Splash screen with Bismillah
- Sidebar help panel (FAQ, How-To, Wiki)
- Keyboard shortcuts (1-4 for answers, Enter to start, Escape to close help)
- Sound effects via Web Audio API (toggle on/off)
- High score persistence via localStorage
- Theme, language, and mute preferences persisted
- Progress bar and score tracking
- Activity log
- Timer
- Back-link to catalog
