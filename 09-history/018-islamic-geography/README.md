# Islamic Geography

Interactive educational app about Islamic Geography.

## Concept

A scenario-based interactive quiz teaching children about Islamic Geography based on Islamic sources.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Keyboard shortcuts
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Muslim geographers mapped the world with remarkable accuracy, traveling further and documenting more than any other civilization of their time.
