# Golden Age Timeline

**Order the milestones of Islamic civilization**

An interactive single-file HTML game for Muslim kids to learn Islamic history by placing events in chronological order. Part of the Workshop-Diy catalog.

## How to Play

1. Open `index.html` in any modern browser
2. Click **Start Mission** on the splash screen
3. Choose a difficulty level (Easy / Medium / Hard)
4. Tap the shuffled event cards in chronological order — earliest first
5. Correct picks are placed on the timeline with a brief description
6. Wrong picks flash red and count as a mistake
7. Complete the timeline with the fewest mistakes possible

## Difficulty Levels

| Level  | Events | Description                              |
|--------|--------|------------------------------------------|
| Easy   | 10     | Major milestones only                    |
| Medium | 15     | Key events across all centuries          |
| Hard   | 25     | Full timeline, 7th through 16th century  |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 color themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Web Audio sound effects (no audio files)
- High score persistence via localStorage
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Keyboard shortcuts (Enter to start, 1-9 to pick cards, Escape to close help)
- Responsive design for phone, tablet, and desktop

## Technical Details

- **HS_KEY:** `wdiy-hs-golden-age`
- **Persisted prefs:** theme, language, sound mute state
- **No external requests** — fonts loaded once, then everything is local
