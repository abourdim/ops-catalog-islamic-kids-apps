# Hadith About Kindness — Interactive Scenarios

Collection of hadiths about kindness with interactive scenario-based responses.

## Concept

Children read hadiths about kindness then face real-life scenarios where they must choose the kindest response. This connects prophetic teachings to practical daily situations.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR) with RTL
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sounds, localStorage persistence
- 12 real-life kindness scenarios

## Lesson

Kindness is a cornerstone of Islam. The Prophet showed kindness to everyone — children, animals, neighbors, and even enemies.
