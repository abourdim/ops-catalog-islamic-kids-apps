# Hadith Collections — Explore the Six Books

Interactive exploration of the six major hadith collections (Kutub al-Sittah) with a quiz game.

## Concept

Children learn about the six canonical hadith collections — who compiled them, when, how many hadiths each contains, and what makes each unique. A matching quiz tests their knowledge.

## The Six Collections

| # | Collection | Compiler | Approx. Hadiths |
|---|-----------|----------|----------------|
| 1 | Sahih al-Bukhari | Imam al-Bukhari (d. 870 CE) | 7,275 |
| 2 | Sahih Muslim | Imam Muslim (d. 875 CE) | 7,500 |
| 3 | Sunan Abu Dawud | Abu Dawud (d. 889 CE) | 4,800 |
| 4 | Jami' al-Tirmidhi | Imam al-Tirmidhi (d. 892 CE) | 3,956 |
| 5 | Sunan al-Nasa'i | Imam al-Nasa'i (d. 915 CE) | 5,700 |
| 6 | Sunan Ibn Majah | Ibn Majah (d. 887 CE) | 4,341 |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR) with RTL
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sounds, localStorage persistence
