# Prophet Sayings — Flashcard Memorization

Flashcard-based memorization of short, essential Prophet sayings with spaced repetition.

## Concept

Children flip through flashcards showing short hadiths in Arabic with translation. They mark each as "learned" or "review again" to build a personal memorization tracker.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR) with RTL
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sounds, localStorage persistence
- 20 essential short hadiths
- Flashcard flip animation

## Lesson

Short hadiths are easy to memorize and carry immense wisdom. A few words from the Prophet can guide a lifetime.
