# Hadith Daily Life — Decision Game

Apply hadiths to daily life situations through an interactive decision-making game.

## Concept

Children face everyday scenarios (at school, home, playground, market) and must choose the response that best matches prophetic guidance. Each decision links to a specific hadith.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR) with RTL
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sounds, localStorage persistence
- 15 daily life decision scenarios

## Lesson

The Prophet's teachings are not just for the mosque — they guide every moment of our daily lives.
