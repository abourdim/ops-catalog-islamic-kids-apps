# Hadith Completion — Fill the Gap

Interactive game where kids complete the missing part of well-known hadiths.

## Concept

Children see a hadith with a key word or phrase blanked out and must choose the correct completion from multiple options. This builds memorization of essential prophetic sayings.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 15 hadiths with blanked portions
- High score persistence via localStorage

## Lesson

Memorizing the exact words of the Prophet helps us carry his guidance in our hearts and apply it in daily life.
