# Hadith Match

**Complete the words of the Prophet ﷺ**

An interactive hadith matching game for Muslim kids. Players see the beginning of a famous hadith and must pick the correct ending from 4 choices. After each answer, the full hadith text, source, and a kid-friendly lesson are displayed.

## Features

- **30 authentic hadiths** covering: intention, brotherhood, self-control, charity, speech, Quran, cleanliness, worldly life, knowledge, ease, kindness to parents, neighbor rights, mercy, love, gentleness, patience, gratitude, honesty, trust, humility, feeding others, visiting the sick, planting trees, removing harm, good character, inner beauty, peaceful conduct, path of knowledge, helping others, forgiveness
- **3 difficulty levels**: Easy (10), Medium (15), Hard (25+)
- **Full hadith explanation** after each answer with source (Bukhari, Muslim, Tirmidhi, etc.) and kid-friendly lesson
- **8 CSS themes**: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- **3 languages**: English, French, Arabic (with RTL support)
- **Progress bar, timer, score tracking, high score** (persisted in localStorage)
- **Splash screen** with Bismillah, Start Mission, lang/theme switchers
- **Sidebar help** with FAQ, How-To, and Wiki tabs
- **Keyboard shortcuts**: 1-4 for answers, Enter to start, Escape to close help
- **Sound effects** via Web Audio API (no external files)
- **Single HTML file**, zero dependencies, fully offline

## Usage

Open `index.html` in any modern browser. No server required.
