# Hadith Sciences

**Learn about hadith classification**

An interactive learning game for Muslim kids to explore hadith classification types and the major hadith collections.

## Game Modes

### 1. Classification
A description of a hadith type is shown. The player picks the correct term from 4 options.

**Types covered:**
- **Sahih** — Authentic, sound hadith
- **Hasan** — Good hadith
- **Da'if** — Weak hadith
- **Mawdu'** — Fabricated hadith
- **Mutawatir** — Mass-transmitted hadith
- **Ahad** — Single-chain hadith
- **Marfu'** — Attributed to the Prophet (peace be upon him)
- **Mawquf** — Attributed to a Companion
- **Maqtu'** — Attributed to a Tabi'i

### 2. Books Match
A fact about a hadith collection is shown. The player picks the correct book from 4 options.

**Books covered:**
- Sahih al-Bukhari
- Sahih Muslim
- Sunan Abu Dawud
- Jami' at-Tirmidhi
- Sunan an-Nasa'i
- Sunan Ibn Majah
- Muwatta Malik
- Musnad Ahmad

After a correct answer, a full explanation is shown including the compiler's name, era, and collection size.

## Difficulty Levels

| Level  | Classification Types         | Books               | Rounds |
|--------|------------------------------|----------------------|--------|
| Easy   | Sahih, Hasan, Da'if          | Bukhari, Muslim      | 8      |
| Medium | + Mawdu', Mutawatir, Ahad    | + Abu Dawud, Tirmidhi, Nasa'i | 12 |
| Hard   | + Marfu', Mawquf, Maqtu'     | + Ibn Majah, Muwatta, Musnad  | 15 |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (with RTL support)
- Web Audio sound effects (no files needed)
- Keyboard shortcuts: 1-4 for answers, Enter to start, Escape to close help
- High score persistence via localStorage
- Theme and language preferences persist across sessions
- Sidebar help panel with FAQ, How-To, and Wiki tabs
