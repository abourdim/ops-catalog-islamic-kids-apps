# Hadith Treasure Hunt

Interactive canvas treasure map where kids dig at locations to find buried hadiths of the Prophet ﷺ.

## Concept

A procedurally generated desert landscape hides 8 authentic hadiths at random locations. Players tap/click on the map to dig. Subtle X marks hint at treasure locations. Each discovered hadith is displayed in Arabic with translation. Goal: collect all 8 with minimum digs.

## Features

- Single HTML file, zero dependencies, fully offline
- Canvas-based desert treasure map with procedural generation
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Touch and click support
- High score persistence via localStorage (efficiency score)
- Theme/language/sound preferences persisted

## Lesson

Each hadith teaches a core Islamic value — intentions, knowledge, brotherhood, speech, safety, charity, cleanliness, and seeking knowledge.
