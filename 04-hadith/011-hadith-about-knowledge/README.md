# Hadith About Knowledge — Matching & Memory Game

Hadiths about seeking knowledge presented as a matching and memory card game.

## Concept

Children flip cards to match hadiths about knowledge with their meanings, building memorization through a fun memory game format.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR) with RTL
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sounds, localStorage persistence
- Memory card matching mechanic

## Lesson

Islam places the highest value on seeking knowledge. The first word revealed was "Read!" (Iqra).
