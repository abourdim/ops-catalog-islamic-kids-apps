# Hadith Authenticity — Classification Game

Interactive game teaching kids about hadith grading: Sahih (authentic), Hasan (good), and Da'if (weak).

## Concept

Children learn the science of hadith classification by reading descriptions of hadith chains and determining their grade. This introduces the fundamental concept of hadith verification in Islamic scholarship.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- 12 scenarios about hadith grading
- High score persistence via localStorage

## Lesson

Not all reported sayings are equally reliable. Islamic scholars developed a rigorous science to verify hadiths, ensuring the Prophet's true teachings are preserved accurately.
