# 40 Nawawi — Interactive Hadith Learning Game

An offline, single-file HTML game for Muslim kids to learn Imam Nawawi's 42 foundational hadiths through flashcards and quizzes.

## Features

- **Two Modes**: Learn (browse flashcards) and Quiz (multiple-choice test)
- **42 Hadiths**: Complete collection with Arabic text, English meaning, topic, and practical kid-friendly lessons
- **Three Difficulty Levels**: Easy (10 most famous), Medium (20), Hard (all 42)
- **8 CSS Themes**: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- **Trilingual UI**: English, French, Arabic (with RTL support)
- **Sound Effects**: Web Audio API — correct, wrong, and win sounds (toggleable)
- **High Score**: Persisted in localStorage
- **Keyboard Shortcuts**: 1-4 for quiz answers, arrow keys for flashcard navigation, Enter to start, Escape to close help
- **Fully Offline**: Single HTML file, zero dependencies
- **Responsive**: Works on phone, tablet, and desktop

## Hadith Coverage

Includes key hadiths: #1 Intentions, #2 Jibril hadith, #3 Five Pillars, #4 Creation stages, #5 Innovations, #6 Halal/Haram, #7 Sincerity, #9 Avoid prohibitions, #10 Purity, #13 Love for brother, #15 Good speech, #16 Don't be angry, #17 Ihsan, #18 Taqwa, #19 Be mindful of Allah, #20 Modesty, #22 Enter Paradise, #24 Injustice forbidden, #25 Charity for joints, #27 Good character, #33 Burden of proof, #34 Change evil, #36 Helping brother, #40 Be a stranger, #41 Follow Prophet, #42 Allah's forgiveness, and more.

## Usage

Open `index.html` in any modern browser. No server or internet required.
