# Hadith Qudsi — Divine Hadiths

Learn about Hadith Qudsi — special divine hadiths where Allah speaks through the Prophet.

## Concept

Children learn the difference between Hadith Qudsi (divine hadiths) and regular hadiths, then explore beautiful examples where Allah speaks in the first person through His Messenger.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR) with RTL
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sounds, localStorage persistence
- 12 Hadith Qudsi with explanations
- Classification quiz: Qudsi vs Regular

## Lesson

Hadith Qudsi represents Allah's words conveyed through the Prophet in the Prophet's own wording — a unique category between Quran and regular hadith.
