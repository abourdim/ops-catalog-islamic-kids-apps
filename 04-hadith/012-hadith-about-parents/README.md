# Hadith About Parents — Scenario Responses

Hadiths about honoring parents with interactive scenario-based responses.

## Concept

Children learn hadiths about the importance of parents, then face scenarios where they choose how to best honor and respect their parents based on prophetic guidance.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes, trilingual (EN/FR/AR) with RTL
- Splash screen with Bismillah, sidebar help panel
- Web Audio API sounds, localStorage persistence
- 12 parent-honoring scenarios

## Lesson

After worshipping Allah, the highest duty is honoring parents. The Prophet emphasized this repeatedly throughout his life.
