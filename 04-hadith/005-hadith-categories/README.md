# Hadith Categories — Sort & Learn

Interactive sorting game where kids drag/assign hadiths into their correct categories (worship, manners, family, charity, knowledge, etc.).

## Concept

Children are presented with well-known hadiths one at a time and must sort them into the correct category. This builds understanding of how hadiths cover all aspects of life — from worship to daily conduct.

## Categories

| # | Category | Example Topic |
|---|----------|--------------|
| 1 | Worship (العبادة) | Prayer, fasting, pilgrimage |
| 2 | Manners (الأخلاق) | Honesty, patience, humility |
| 3 | Family (الأسرة) | Parents, children, marriage |
| 4 | Charity (الصدقة) | Giving, generosity, helping |
| 5 | Knowledge (العلم) | Seeking knowledge, teaching |
| 6 | Brotherhood (الأخوة) | Unity, compassion, community |

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Keyboard shortcuts (1-6 for categories)
- High score persistence via localStorage
- Theme/language/sound preferences persisted
- 18 hadiths shuffled each playthrough
- Score tracking with progress bar

## Lesson

The Prophet's teachings cover every aspect of life. Islam is not just about rituals — it is a complete way of living that guides our worship, behavior, relationships, and character.
