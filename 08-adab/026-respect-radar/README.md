# Respect Radar

Radar visualization scanning for respectful vs disrespectful behaviors. Interactive classification game.

## Features

- Single HTML file, zero dependencies, fully offline
- Animated radar canvas visualization
- 15 behaviors to classify
- Real-time scoring and accuracy tracking
- Islamic manners education
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Being aware of respectful behavior is the first step to practicing good adab. Islam teaches us to be mindful of our actions.
