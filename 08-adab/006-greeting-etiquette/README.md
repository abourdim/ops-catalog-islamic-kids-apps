# Greeting Etiquette

Interactive app to practice Islamic greetings for different situations.

## Concept

A scenario-based quiz teaching the Sunnah of spreading Salam: greeting on the street, entering homes, answering phones, greeting children, and more.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Keyboard shortcuts
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Spreading Salam builds love between Muslims. The Prophet ﷺ encouraged greeting everyone and taught specific greetings for different occasions.
