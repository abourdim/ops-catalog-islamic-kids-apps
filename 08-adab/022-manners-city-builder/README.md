# Manners City Builder

Build a city where good manners improve buildings. Bad manners cause decay. Grid-based city simulation with Islamic values.

## Features

- Single HTML file, zero dependencies, fully offline
- Grid-based city building on canvas
- 6 building types: Mosque, School, Hospital, Market, Garden, House
- Manner events that boost prosperity
- Population and prosperity tracking
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Good character builds strong communities. Islamic values of greeting, sharing, patience and truthfulness strengthen the social fabric.
