# Islamic Character Builder

RPG-style character sheet for Islamic values. Level up patience, kindness, honesty, gratitude, courage and generosity.

## Features

- Single HTML file, zero dependencies, fully offline
- 6 character stats with XP and leveling system
- 8 loggable actions tied to real-life deeds
- Title progression system (Beginner to Master)
- Visual stat bars with colors
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Good character is the heaviest thing on the scales on the Day of Judgment. Building Islamic character is a lifelong journey.
