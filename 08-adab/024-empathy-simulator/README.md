# Empathy Simulator

See situations from others' perspectives. Switch viewpoints in interactive scenarios to build understanding and compassion.

## Features

- Single HTML file, zero dependencies, fully offline
- 3 rich scenarios with multiple perspectives each
- Click to switch between viewpoints
- Islamic wisdom woven into each scenario
- Perspective counter and progress tracking
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Empathy is a cornerstone of Islamic character. The Prophet (peace be upon him) taught us to love for others what we love for ourselves.
