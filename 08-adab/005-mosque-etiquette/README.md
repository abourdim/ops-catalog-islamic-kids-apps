# Mosque Etiquette

**Learn the adab of the masjid** — A True or False interactive game for Muslim kids.

## Overview

An educational game that teaches children proper mosque etiquette through True/False scenarios. Each question presents a mosque behavior, and the player decides whether it is correct or incorrect. After answering, the ruling is shown along with a hadith reference.

## Features

- **35 scenarios** covering entering the mosque, prayer conduct, khutbah manners, cleanliness, and general adab
- **3 difficulty levels**: Easy (10 obvious questions), Medium (15), Hard (25+)
- **Ruling + hadith reference** displayed after every answer
- **8 CSS themes**: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- **Trilingual**: English, French, Arabic (with automatic RTL)
- **Sound effects** via Web Audio API (no external files)
- **High score** persistence via localStorage
- **Keyboard shortcuts**: 1 = Correct, 2 = Incorrect, Enter = Start/Next, Escape = Close help
- **Sidebar help** with FAQ, How-To, and Wiki tabs
- **Single HTML file**, zero dependencies, fully offline

## Scenarios Cover

- Entering with right foot / dua of entry
- Tahiyyat al-masjid (2 rak'ah greeting prayer)
- Silence during khutbah
- Avoiding garlic/onion before mosque
- Straightening rows, filling front rows first
- Responding to adhan, saying Ameen
- Phone etiquette during salah
- Adhkar after prayer
- Dua between adhan and iqamah
- Using miswak, wearing clean clothes, applying perfume
- Reading Quran, dhikr, i'tikaf
- Not stepping over people, not walking in front of praying person
- Sutrah when praying alone
- Not buying/selling in the mosque
- Children's behavior in the mosque
- And more
