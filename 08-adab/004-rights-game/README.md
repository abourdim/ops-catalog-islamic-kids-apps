# Islamic Rights Game

**Who has this right in Islam?**

An interactive quiz game for Muslim kids to learn about rights and responsibilities in Islam. Players match a right or duty to the correct category from four choices.

## Categories

- **Parents** — obedience, respect, patience, spending on them
- **Neighbors** — no harm, sharing food, checking on them
- **Children** — good name, education, affection, equal treatment
- **Animals** — food/water, no overwork, mercy in slaughter
- **Environment** — no waste, planting trees, cleanliness
- **Teachers** — listening, respect, practicing what they teach
- **Friends** — keeping secrets, sincere advice, salam, visiting the sick
- **The Poor** — zakat, no reminders, dignity, helping them find work

## Features

- 25+ rights sourced from Quran and authentic Hadith
- Quran/Hadith reference shown after each correct answer
- 3 difficulty levels: Easy (10), Medium (15), Hard (25)
- 8 CSS themes (Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand)
- Trilingual UI: English, French, Arabic (RTL)
- Sound effects via Web Audio API (no files)
- High score persistence via localStorage
- Keyboard shortcuts: 1-4 for answers, Enter to start, Escape to close help
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Single HTML file, zero dependencies, fully offline

## Storage Keys

| Key | Purpose |
|---|---|
| `wdiy-hs-rights-game` | High score (percentage) |
| `wdiy-lang` | Language preference |
| `wdiy-theme` | Theme preference |
| `wdiy-mute` | Sound mute state |

## Usage

Open `index.html` in any modern browser. No server or build step required.
