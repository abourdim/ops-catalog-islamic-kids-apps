# Islamic Manners — Adab Scenarios

**What would a good Muslim do?**

An interactive scenario-based game that teaches Islamic manners (adab) to Muslim kids through real-life situations.

## How It Works

Each round presents a real-life scenario. The child picks the best Islamic response from 4 options. After answering, the Islamic teaching (hadith or Quran reference) behind the correct answer is displayed.

## Difficulty Levels

- **Easy** — 10 questions
- **Medium** — 15 questions
- **Hard** — 25+ questions

## Features

- 8 CSS themes (Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand)
- Trilingual (EN / FR / AR with RTL support)
- Splash screen with Bismillah
- Sound effects (Web Audio API, no files)
- Timer, progress bar, score tracking
- High score persistence (localStorage)
- Keyboard shortcuts (1-4 for answers, Enter to start, Escape for help)
- Sidebar help panel (FAQ, How-To, Wiki)
- Single HTML file, zero dependencies, fully offline
