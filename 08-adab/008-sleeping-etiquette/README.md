# Sleeping Etiquette

Interactive guide to Islamic sleeping etiquette and bedtime routines based on the Sunnah.

## Concept

A scenario-based quiz teaching children the Prophet's \u{FDFA} bedtime practices including wudu, sleeping on the right side, bedtime adhkar, and dealing with bad dreams.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Keyboard shortcuts
- High score persistence via localStorage
- Theme/language/sound preferences persisted
- 8 bedtime scenarios with authentic hadith references

## Lesson

Sleep is a trust from Allah. The bedtime Sunnah brings peace, protection, and spiritual connection even while resting.
