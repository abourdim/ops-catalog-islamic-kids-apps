# Daily Routine Planner

Plan an Islamic daily routine by dragging sunnahs and obligations into time slots. Balance worship, study, health, family and fun.

## Features

- Single HTML file, zero dependencies, fully offline
- 17 time slots from Fajr to bedtime
- 18 activities including prayers, study, family time
- Drag-and-drop or click-to-place interface
- Balance score across 5 categories
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Time is a trust from Allah. A balanced routine that includes worship, learning, family and rest leads to a fulfilling life.
