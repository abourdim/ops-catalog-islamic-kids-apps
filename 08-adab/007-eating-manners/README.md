# Eating Manners

Interactive guide to Islamic table manners and eating etiquette based on the Sunnah.

## Concept

A scenario-based quiz teaching children the Prophet's \u{FDFA} etiquette for eating and drinking, including saying Bismillah, eating with the right hand, drinking in three sips, and showing gratitude.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- Keyboard shortcuts
- High score persistence via localStorage
- Theme/language/sound preferences persisted
- 10 eating scenarios with authentic hadith references

## Lesson

Every meal is an opportunity to practice the Sunnah. Islamic table manners teach gratitude, moderation, and mindfulness in everyday life.
