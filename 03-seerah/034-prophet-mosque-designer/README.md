# Prophet's Mosque Designer

Design a mosque following the Prophet's simplicity principles, placing pillars, mihrab, and minbar

## Concept

Design a mosque following the Prophet's simplicity principles, placing pillars, mihrab, and minbar. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

The Prophet's mosque was simple yet functional, teaching that sincerity matters more than grandeur.
