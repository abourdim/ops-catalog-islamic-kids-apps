# Prophet's Schedule Planner

Plan a day following the Prophet's daily routine by placing activities into correct time slots

## Concept

Plan a day following the Prophet's daily routine by placing activities into correct time slots. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

The Prophet's balanced daily routine teaches time management and prioritizing worship.
