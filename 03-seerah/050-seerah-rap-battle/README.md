# Seerah Poetry Battle

Create rhyming couplets about seerah events inspired by Hassan ibn Thabit's poetry

## Concept

Create rhyming couplets about seerah events inspired by Hassan ibn Thabit's poetry. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Hassan ibn Thabit was the Prophet's poet who defended Islam through the power of eloquent verse.
