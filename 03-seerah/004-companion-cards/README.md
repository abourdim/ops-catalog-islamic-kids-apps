# Companion Cards

**Know the Sahaba of the Prophet ﷺ**

An interactive quiz game for Muslim kids to learn about the Companions (Sahaba) of Prophet Muhammad ﷺ. Read a fact or description about a Companion, then pick the correct name from four choices.

## How It Works

1. A clue about a Companion is displayed (a historical fact or description)
2. Four name options are shown — pick the correct one
3. After each answer, a reveal card shows the full biography: name, title, achievement, and when they accepted Islam
4. Track your score and try to beat your high score

## Companions Included (25+)

### Easy Tier (10)
Abu Bakr As-Siddiq, Umar ibn Al-Khattab, Uthman ibn Affan, Ali ibn Abi Talib, Bilal ibn Rabah, Khadijah bint Khuwaylid, Aisha bint Abu Bakr, Fatimah Az-Zahra, Khalid ibn Al-Walid, Salman Al-Farisi

### Medium Tier (+5)
Abu Hurairah, Hamza ibn Abdul-Muttalib, Az-Zubayr ibn Al-Awwam, Talha ibn Ubaydullah, Sa'd ibn Abi Waqqas

### Hard Tier (+11)
Abdur-Rahman ibn Awf, Abu Ubaidah ibn Al-Jarrah, Muadh ibn Jabal, Abdullah ibn Masud, Asma bint Abu Bakr, Khawlah bint Al-Azwar, Umm Amarah (Nusaybah), Sumayyah bint Khayyat, Abu Dharr Al-Ghifari, Muawiyah ibn Abi Sufyan, Abu Musa Al-Ashari

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (with RTL)
- Sound effects via Web Audio API (no files needed)
- Keyboard shortcuts: 1-4 for answers, Enter to start, Escape to close help
- High score persisted in localStorage (`wdiy-hs-companion-cards`)
- Theme, language, and sound preferences persisted
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Responsive design — works on phone, tablet, and desktop

## Tech

- Pure HTML/CSS/JS — no frameworks, no build step
- LocalStorage key: `wdiy-hs-companion-cards`
- Back-link to catalog: `../../index.html`
