What is this?

A detective-style game where you read clues about seerah events and must identify which event is being described.

How does scoring work?

Fewer clues revealed = more points! 4 clues = 1 point, 3 clues = 2 points, 2 clues = 3 points, 1 clue = 4 points.

1

2

If you know the answer, select it. If not, reveal more clues

3

The fewer clues you need, the more points you earn

4

Solve all cases to complete the investigation
