# Seerah Word Adventure

Text adventure game navigating through seerah events with choose-your-path storytelling

## Concept

Text adventure game navigating through seerah events with choose-your-path storytelling. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Making choices within seerah scenarios teaches Islamic values through experiential learning.
