# Caravan Trade Simulator

Trade caravan simulator traveling routes the Prophet traveled as a merchant, buy and sell goods

## Concept

Trade caravan simulator traveling routes the Prophet traveled as a merchant, buy and sell goods. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

The Prophet was known as Al-Amin (The Trustworthy) for his honest trade practices.
