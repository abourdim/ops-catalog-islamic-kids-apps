# Seerah Timeline Builder

Drag-and-drop events onto a timeline to build the complete seerah chronology

## Concept

Drag-and-drop events onto a timeline to build the complete seerah chronology. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Understanding chronological order helps children see how seerah events connect and build upon each other.
