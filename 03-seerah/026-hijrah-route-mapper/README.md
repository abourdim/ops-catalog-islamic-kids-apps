# Hijrah Route Mapper

Canvas map where kids trace the hijrah route from Mecca to Medina, marking stops, caves, and landmarks

## Concept

Canvas map where kids trace the hijrah route from Mecca to Medina, marking stops, caves, and landmarks. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

The Hijrah journey teaches trust in Allah and the importance of sacrifice for faith.
