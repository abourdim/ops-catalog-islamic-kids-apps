# Seerah Comic Strip

Create comic strips of seerah events with emoji scenes, speech bubbles, and panel arrangements

## Concept

Create comic strips of seerah events with emoji scenes, speech bubbles, and panel arrangements. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Visual storytelling helps children engage with and remember seerah events creatively.
