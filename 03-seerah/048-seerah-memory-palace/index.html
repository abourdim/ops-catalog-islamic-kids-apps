What is a memory palace?

A learning technique where you associate information with rooms in an imaginary building. Walking through rooms helps you recall information in order.

1. Click a room to enter it. 2. Read about the seerah event. 3. Answer the quiz to mark the room complete. 4. Visit all 9 rooms.
This technique was used by ancient scholars. Islamic scholars also had amazing memory systems for preserving hadith and Quran.
