# Ancient Mecca Explorer

Top-down exploration of ancient Mecca navigating streets, visiting Ka'bah, Safa-Marwa, and important houses

## Concept

Top-down exploration of ancient Mecca navigating streets, visiting Ka'bah, Safa-Marwa, and important houses. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Exploring Mecca connects children to the birthplace of Islam and the legacy of Ibrahim.
