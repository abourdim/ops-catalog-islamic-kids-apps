# Seerah Board Game

Digital board game moving through Prophet's life events, roll dice and answer to advance

## Concept

Digital board game moving through Prophet's life events, roll dice and answer to advance. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Walking through the Prophet's life chronologically builds a complete picture of the seerah.
