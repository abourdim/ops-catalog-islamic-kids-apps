# Hijrah Journey

**Follow the Prophet's migration to Medina**

An interactive step-by-step game for Muslim kids that teaches the story of the Hijrah from Mecca to Medina. Events are presented as shuffled cards — the player taps them in correct chronological order.

## How to Play

1. Open `index.html` in any modern browser
2. Choose a difficulty level (Easy / Medium / Hard)
3. Press **New Game**
4. Tap the event cards in the correct chronological order
5. After each correct tap, read the event description and Islamic lesson
6. Watch the map canvas as the journey dot moves from Mecca to Medina

## Difficulty Levels

- **Easy** — 8 key events
- **Medium** — 12 events
- **Hard** — All 15 events

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- Trilingual UI: English, French, Arabic (RTL)
- Canvas map showing Mecca → South → Cave Thawr → North → Medina with animated progress dot
- Event descriptions with Islamic lessons after each correct answer
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Keyboard shortcuts (Enter to start)
- Responsive design for phone, tablet, and desktop

## Storage

- `wdiy-hs-hijrah` — High score (localStorage)
- `wdiy-lang` — Language preference
- `wdiy-theme` — Theme preference
- `wdiy-mute` — Sound preference
