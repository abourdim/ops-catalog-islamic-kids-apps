# Ambassador Simulator

Be an ambassador for the Prophet navigating diplomatic situations with tribes and nations

## Concept

Be an ambassador for the Prophet navigating diplomatic situations with tribes and nations. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

The Prophet was the greatest diplomat, using wisdom and respect to build alliances for peace.
