# Medina City Builder

Build the city of Medina by placing masjid, market, houses, and farms with resource management

## Concept

Build the city of Medina by placing masjid, market, houses, and farms with resource management. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Building Medina teaches community planning and the importance of the masjid as the center of Muslim life.
