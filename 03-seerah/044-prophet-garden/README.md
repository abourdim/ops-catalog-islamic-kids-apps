# Prophet's Garden

Grow a virtual garden inspired by the Prophet's love of nature, plant, water, and harvest

## Concept

Grow a virtual garden inspired by the Prophet's love of nature, plant, water, and harvest. An interactive educational app for Muslim kids in the Seerah category.

## Features

- Single HTML file, zero dependencies, fully offline
- 8 CSS themes: Terminal, Midnight, Ember, Arctic, Phosphor, Signal, Redshift, Sand
- Trilingual: English, French, Arabic (with RTL support)
- Splash screen with Bismillah
- Sidebar help panel with FAQ, How-To, and Wiki tabs
- Web Audio API sound effects (no audio files)
- High score persistence via localStorage
- Theme/language/sound preferences persisted

## Lesson

Planting trees is sadaqah jariyah (ongoing charity) and the Prophet loved nature and greenery.
