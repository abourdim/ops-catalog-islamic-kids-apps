# Prophet's Family — Family Tree Quiz

**Know the family of Muhammad ﷺ**

An interactive quiz game for Muslim kids to learn about the family members of Prophet Muhammad ﷺ — their names, relationships, Arabic names, and roles in Islamic history.

## Features

- **20+ family members**: Parents, grandparents, uncles, wives, daughters, sons-in-law, grandchildren, caretakers, and adopted son
- **3 difficulty levels**: Easy (10 closest family), Medium (15 members), Hard (20+ members)
- **Fact cards**: After each answer, displays Arabic name, relationship, and a key historical fact
- **8 CSS themes**: Terminal, Midnight, Ember, Phosphor, Signal, Redshift, Arctic, Sand
- **Trilingual**: English, French, Arabic (with RTL support)
- **Sound effects**: Web Audio API — correct, wrong, and win sounds (toggle on/off)
- **High score**: Persisted in localStorage
- **Keyboard shortcuts**: 1-4 for answer options, Enter to start, Escape to close help
- **Sidebar help**: FAQ, How-To, and Wiki tabs
- **Offline**: Single HTML file, zero dependencies, no external calls
- **Responsive**: Works on phone, tablet, and desktop

## Usage

Open `index.html` in any modern browser. No server required.

## Storage Keys

- `wdiy-hs-family-tree` — High score (percentage)
- `wdiy-lang` — Language preference
- `wdiy-theme` — Theme preference
- `wdiy-mute` — Sound mute state
